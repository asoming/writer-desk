# 作家工作台 · Writer’s Desk

个人使用的中文写作程序。长篇与短篇分别管理，可以同时创作多部作品；每本书都有自己的封面、大纲、人物脉络图与正文。写作、保存、备份与恢复均可离线使用，AI 辅助按需启用。


桌面版采用独立窗口，Linux 已提供可直接运行的发行包。解压后运行 `writer-desk`，无需另外安装 Python；`install-linux.sh` 将程序复制到用户安装目录，并注册固定的应用菜单入口。此后可从「设置 → 安装与升级」安装新版升级包，旧入口会继续启动新版本。Windows / macOS 提供构建配置，需在对应系统构建，当前未验证其安装包。

左下角「设置 → 通用 → 界面语言」可切换中文和 English，切换前自动保存当前作品。只翻译界面，书名、正文、大纲和人物资料保持原文。

顶部保存状态左侧的太阳／月亮图标可切换白天和黑夜模式。「设置 → 通用」中可开启护眼模式，白天使用暖纸色，黑夜使用暖灰色；外观选择保存在本机，重开后恢复。

首次打开书架即有原创群像小说《潮汐档案馆》，含六卷三十六章、三十二位人物、四十九条大纲节点、六个主题分图和三十五条手动关系。升级已有作品库也会补入缺少的完整示例，保留已有作品及修改。书架的「载入长篇示例」仍可新建独立副本。正文共 101,506 个非空白字符，字数包含标点和英文字母；完整验证结果见 [验收记录](docs/acceptance-report.md)。

桌面端数据库位于系统应用数据目录 `writer-desk` 下，程序更新不会把作品写入安装目录；本地网页版仍使用应用目录 `data/`。保留旧版 `data/` 在源码旁首次运行可复制旧库，原文件保留。开发与打包说明见 `desktop/BUILD.md`。

## 网页版启动

需要 Python 3.9 或更新版本，无需安装其他依赖。

- Linux / macOS：在解压后的源码目录运行 `bash start.sh`。
- Windows：安装 Python 后双击 `start.bat`。支持 `py` 启动器，也支持已加入 PATH 的 `python`。
- 也可以运行 `python3 server.py --open`，然后打开终端显示的本机地址。默认地址为 `http://127.0.0.1:8765/`。

启动后保持终端窗口开启。退出前确认右上角显示「已保存」，再在终端按 Ctrl+C。服务仅监听本机地址。

如果端口被占用，可以运行 `python3 server.py --port 8766 --open`，或 `bash start.sh --port 8766`。Windows 可在命令提示符中运行 `start.bat --port 8766`。换端口仍使用同一数据库。

## 书架与写作

书架分为长篇和短篇，均以封面与书名展示作品，长篇显示卷章数，长短篇均显示字数和最近编辑时间。通过「封面与书名」修改作品信息。书名右侧的骰子离线随机取名，保存后生效。可选择十款不同风格的模板封面，模板随书名更新；也可上传 PNG、JPG 或 WebP，或使用文字封面。封面随作品保存和备份。 每本书右侧的「打开文件夹」会先保存当前编辑，再用系统文件管理器打开该书的独立目录，长篇和短篇都可使用。首次点击生成 `正文.txt` 和 `作品.yejian.json`，此后的成功保存会同步更新；正文按卷章排序并过滤回收内容，完整备份保留全部资料、分类与关联。改名不改变目录，同名书也不共用目录。额外放入的文件保留；外部修改过的导出文件不会被覆盖，也不会自动写回 App。网页版显示可复制的目录路径。

点击「新建长篇 / 新建短篇」后，先进入这部作品的大纲。新长篇可以暂时没有正文章节，先整理故事、人物与分卷构思；短篇直接拥有一篇空白正文。书架上的「大纲」「人物脉络」「开始正文 / 继续写作」分别打开该作品的相应页面；左侧的大纲、人物脉络和统一的「写作」入口只打开当前作品。切换作品时返回书架，再点击封面或书名直接进入写作；长篇显示卷章目录，短篇显示连续正文，也可通过对应按钮进入大纲或人物页；切换长短篇类型也先进入相应书架，不会自动打开另一部作品。页面只保留一个静态书名，不再设置作品下拉框。各书的数据相互独立。

长篇按照「卷 → 章节」组织目录。卷可展开或收起；目录搜索会同时查找章节标题和正文。可编辑卷名与分卷说明、调整卷的顺序，并在卷下新建章节；章节也可以移到另一卷，或暂时保留为未分卷。回收卷前需先移走其中的活动章节。短篇是一篇连续正文，不设卷章目录，也不能新建篇章。旧版短篇的活动正文按原顺序用空行完整衔接，回收内容保留，首次保存前的原始数据保留在历史中；已有大纲、人物与 AI 引用仍可打开同篇正文。短篇导出只包含书名与正文，AI 草稿可追加或替换正文。长篇目录里的铅笔可重命名章节，与正文标题双向同步，关联保持；目录底部显示全书总字数。作品名称只通过书架的「封面与书名」修改。

正文使用纯文本，支持中文输入法和浏览器原生撤销、重做。停止输入约 0.65 秒后自动保存；Ctrl+S / Command+S 立即保存。可以新建、改名和调整章节顺序，收起目录、打开关联与资料，或进入专注模式。Esc 退出专注模式。

字数包含标点和英文字母，不计空格、换行；正文字号可在 16–26 px 之间调整。

大纲与写作页的目录、正文和 AI / 资料栏边界可拖动调整，按页面记住宽度。双击边线恢复默认，也可用键盘方向键调整。设置使用浅灰侧栏与白色分组内容，按通用、AI、写作 Skill、保存、快捷操作、升级和关于分类。

## 大纲、人物与正文跳转

跳转方式参考「从这里开始」式入口，保留同一作品上下文，以具体章节为定位单位。

1. 先选定作品，在「大纲」整理全书总纲、分卷大纲、章节大纲和情节 / 设定节点。可以添加子节点、调整层级和顺序，并设置所属卷。大纲搜索会查找标题与内容，同时保留命中节点的上级路径。
2. 长篇可用「生成卷章目录」按分卷大纲与章节大纲建立卷和空白章节，也可从单条章纲创建正文。大纲内容继续保留为策划，不会填入空白正文；已有的卷章与正文会保留，已关联的目录不会重复创建。「完整阅读」以连续文档展示整本书的大纲。左侧目录是文字链接，点击可定位对应段落；点击正文标题编辑该节，点击关联章节的文字进入正文。阅读模式去掉分卷卡片、重复分类块和层级标签，主题、层级和卷筛选收在「大纲分类」中，默认收起。故事主线、世界设定、人物设定、分卷剧情、伏笔回收、连续性检查、结局场景、参考资料和情节与设定分别分类，也可以输入自定义主题；主题、层级和卷可组合筛选，目录可折叠。
3. 在「人物脉络」添加人物、填写档案，再建立两个人物之间的关系。点击图中的人物会选中档案，点击连线会打开关系详情；搜索框可以查找人物。关联选择框支持搜索，章节同时显示所属卷。
4. 大纲节点、人物档案和关系详情中的「关联章节」可以连接多个正文章节。点击关联章节即可进入正文。
5. 正文上方的「关联大纲 / 人物」也可以建立关联。「关联与资料」侧栏显示本章的大纲、人物与关系，点击可返回相应页面并选中该条目。
6. 从大纲或人物图进入正文后，会定位到章首并展开所在卷，可点击「返回大纲 / 返回人物脉络」。

关联使用固定章节编号，因此改名和排序后仍然有效。当前版本定位到章节，不追踪正文中的某一个段落。移入回收站的章节不能直接打开，恢复后原关联重新可用。

人物图与人物资料共用数据，改名会同步。人物关系弹窗中的文字与人物选择也会自动保存。人物、地点、世界观和灵感资料可在写作侧栏编辑。

## 人物档案与正文提及

人物档案可填写姓名、别名与正文称呼、人物介绍，以及创作档案中的分组、身份与定位、愿望与目标、矛盾与弱点、最终去向。长篇还可按卷记录人物变化与关键行动，形成分卷人物弧线。关系由你编写名称、类型、阶段、说明及关联卷和章节。

登记人物姓名与别名后，程序按这些称呼匹配本书未回收章节的正文，生成「正文自动提及」索引；两个人物在同一章被提及时，会显示「同章提及」线索。索引随正文修改更新，可从关联章节跳转阅读。提及可能来自回忆、对白或转述，不代表人物实际出场；同章提及也不表示友谊、亲属、冲突或其他已确认关系。图中的实线表示手动编写的关系，虚线表示同章提及。

「从正文识别人名」用本地规则寻找部分“姓名＋说／问”等对白写法，展示待确认候选与正文片段。它可能漏认或误认，需要你检查、修改并确认后才会建立人物档案。此功能不调用 AI，也不推断人物关系、心理或故事因果；仍可直接手动建立人物。

人物图提供三套独立分类。上方主题分图可以自由命名并选择成员，同一人物可属于多张图；彩色分组区分人物身份或阵营；关系类型筛选区分友谊、亲属、冲突等。默认核心图以主角为中心，较大的主题图使用 Dagre 分层布局；并行关系分别排线。点选人物可突出相关连线，右侧默认阅读档案，需要修改时点击「编辑人物」。分卷推进卡可筛选本卷人物与关系，完整关系索引以表格展示双方、类型阶段和具体变化。

图谱中的「显示同章提及」控制自动连线，默认关闭。关系索引默认只显示手动关系，使用自己的类型筛选；索引与图谱都遵循主题、分组、卷和人物范围。人物搜索支持姓名、别名和分组。人物图支持放大、缩小、适应图幅，以及拖动空白区域平移。大图可滚动浏览，不会为了塞入整个网络而把人物名字压得过小。

已载入并修改的示例保持原内容，不会在升级或重启时覆盖；若已有版本缺少主题分图与完整策划，可从书架再次「载入长篇示例」，创建新版独立副本。自己的旧作品仍可直接编辑分类和新建分图。

## 保存、导出与恢复

桌面 App 的数据库位于用户数据目录 `writer-desk/data/writer.sqlite3`，可从「设置 → 关于 → 本机数据目录 → 打开文件夹」查看。网页启动模式的数据库位于应用目录 `data/writer.sqlite3`。没有云端同步。

每本书右侧的「导出与备份」只操作这部书，打开时会显示书名，并提供以下选项。

- TXT / Markdown 正文，只包含未移入回收站的正文章节。
- 完整 JSON 备份，包含所选作品的分类、封面、分卷及说明、章节所属卷、大纲主题分类、层级与类型、主题分图及成员、人物别名与创作档案、分卷人物弧线、人物关系类型与阶段、卷章关联和回收站。
- 书架的「导入备份」创建一部新作品，不覆盖已有作品。新版导出 v3 备份，同时兼容早期 v1、v2 备份；未记录作品分类的旧备份默认为长篇。旧长篇会补齐默认卷并保留原章节与正文，恢复时会更新新作品的卷编号及相关引用。

一份 JSON 备份只包含所选作品。请定期复制备份到其他磁盘。移动整个程序时，先关闭服务，再复制整套应用与 `data` 目录；服务运行时不要只复制 SQLite 主文件，因为近期写入可能仍在 WAL 文件中。

浏览器会尽力缓存未完成的输入，便于异常关闭后恢复草稿。该临时缓存不代替数据库和独立备份。清理浏览器数据不会删除已经确认写入数据库的作品。

保存失败时会显示错误，并保留本页内容，可重试保存或下载本页备份。同时打开两个窗口编辑同一作品时，程序会检测版本冲突，允许把本页内容另存为新作品，避免直接覆盖另一个窗口。

书架每本书右侧的「移入回收站」可回收整部作品，长篇和短篇都支持。回收前先保存当前编辑；书籍从书架和计数中移除，但正文、封面、大纲、人物、卷章、关联及历史保留。左下角「回收站」可以恢复整本书，即使没有打开作品也能使用。整部作品移入满 30 天后自动彻底删除；App 关闭期间到期的，下次启动时清理。回收站也可手动「彻底删除」，确认后清除该书、保存历史和本机自动快照，不能从 App 恢复。已经另行导出的文件保留。回收或彻底删除默认示例后，重启不会自动补回；书架全部清空后也不会重新种入默认作品。

卷、章节、大纲节点、人物资料和人物关系也可单独移入回收站，再从当前作品的回收区恢复；允许将最后一个正文章节移入回收站，继续保留大纲和人物策划。这些单条回收内容保留恢复功能；整部作品可在作品回收站彻底删除。

## 自动备份与历史恢复

「设置 → 保存」可设置自动备份开关、间隔及每本书保留份数。自动备份默认开启，默认每 5 分钟在成功保存后生成一份，保留最近 20 份；没有编辑时不会反复生成同样的快照。也可随时立即备份。备份为独立 JSON 文件，位于本机数据目录的 `backups/` 中，可以复制到其他磁盘。

每本书的「导出与备份 → 历史与自动备份」可以查看该书的历史保存版本和自动备份，先预览正文、大纲及人物等内容，再恢复。恢复前会保留当前版本，因此可以撤回这次恢复。另一窗口已修改作品时会阻止过期恢复，避免覆盖新内容。备份写入失败会提示，但已成功保存的正文仍保留。

## AI 辅助

配置兼容接口的服务地址和密钥后，程序从 `/models` 自动读取可用模型；可在设置或对话输入框底部选择、刷新，接口不支持列表时保留自定义模型。列表读取不发送作品。切换模型会保存为当前默认，正在发送的请求仍使用发送时选定的模型。

「设置 → AI 服务」中填写兼容 Chat Completions 的服务地址、模型名称及密钥，再启用。服务地址填写 `/v1` 等 API 基础地址，具体以服务提供方为准；支持 HTTPS 服务及本机 HTTP 服务。密钥只保存在本机数据目录的独立配置中，不进入作品、备份或发行包，界面只显示是否已设置。可测试连接或清除密钥。

大纲和正文页右侧内置 AI 对话栏，底部输入提示词，点击右侧发送按钮或按 Enter 发送，Shift+Enter 换行；中文输入法选字时不会发送。主编辑区保持可写。每本书分别保存大纲和写作对话，包含未发送的提示词；收起、切换页面、重开 App 或切换语言后仍可继续。点击「新对话」开始新的交流。对话记录仅保存在本机界面数据中，作品 JSON 备份不包含对话记录。

可自由讨论构思，也可选择生成大纲、生成写作草稿、提取人物与关系或检查一致性。预设提示词可修改、恢复；后续追问会携带当前对话前文和此前候选，候选不视为已采用。资料与写作 Skill 选择收在折叠区；每轮参考当前选择的章节、已有大纲与人物资料。上下文默认由配置的模型服务校验，不使用固定字符上限，也不自动删减资料；需要时可在 AI 设置的高级选项中启用手动字符保护，历史对话同样计入总数。点击发送才会调用配置的服务。

生成结果在对话中审阅。大纲先编辑、勾选，再明确追加到本书，之后可用「生成卷章目录」建立正文目录；严格空白的新书模板会复用默认第一卷。草稿由你选择追加或保存为新章节；人物与关系由你勾选确认，一致性问题可跳转到原章节核对。已有正文与策划不会因聊天自动改写。采用后可以继续对话，保存失败可重试，不会重复追加。人物页和「封面与书名」保留独立预览窗口。普通保存和本地规则提及索引不调用 AI。

「封面与书名」中的 AI 入口也可用于尚未保存的新书。先生成候选书名和封面提示词，修改后再点击「生成封面」。在 AI 设置填写同一服务支持的图像模型；图片通过该服务的 Images API 请求，需服务实际支持图像生成。候选先预览，明确采用后才回填编辑框或保存当前书；书名排版在本机完成。生成名字不调用图像服务，改书名也不重复生成图片。

图像接口依据 [Images API](https://developers.openai.com/api/reference/resources/images/methods/generate)，使用同一已配置服务及密钥；仅接受内联 PNG、JPEG、WebP，不自动下载服务返回的外部图片地址。测试使用本机模拟服务验证请求、预览和保存，没有调用真实付费模型。

提示词框随内容和分栏宽度自动增高或缩回，长提示词在框内滚动。底部「＋」或粘贴可添加 PNG、JPEG、WebP 图片，发送前可预览及移除；对话里的图片可点击查看大图，Esc 关闭。每条消息最多 4 张，每张不超过 8 MiB，单次请求当前与历史图片合计不超过 20 MiB。图片原件单独保存在本机数据目录 `ai-chat-images/`，对话偏好只记录引用，重开后恢复；移入回收站保留，彻底删除作品及 30 天清理会删除该书的对话图片。作品备份与源码发行包不含对话图片。

图片仅在点击发送时随提示词交给已配置服务；本机预览和上传不调用外部 AI。识图需选择支持图片输入的模型，按 [官方 OpenAI 图片消息格式](https://developers.openai.com/api/docs/guides/images-vision?api-mode=chat) 发送。兼容服务返回的内联 PNG、JPEG、WebP 图片可显示；不自动抓取外部图片链接，无法显示的图片给出提示并保留文字答复。不会因为普通对话自动调用封面生成模型。

## 本机写作 Skill

「设置 → 写作 Skill」可以导入本机已下载的 `chinese-novelist`、`novelskill` 和 `human-writing`，查看规则与 Markdown 参考，保存默认选择。来源为 `$CODEX_HOME/skills`，未设置时使用 `~/.codex/skills`。导入副本保存在本机数据目录的 `writing-skills/`，原文件保持不变；源文件更新后可再次导入。

AI 对话框可以临时选择多个 Skill，或取消全部选择，并指定章节、续写、润色、大纲、人物或检查任务。自动模式随当前操作选择相关规则。预览会列出本次会用的参考文件，Skill 文本包含在实际发送的上下文中；点击发送后才会连同所选作品资料交给已配置的 AI 服务。Skill 提供写作规则，需要配合模型使用；程序不执行其中的脚本，也不会自动建立外部小说目录。

Skill 原文、本机导入副本和默认选择不放进作品备份、GitHub 或发行包。其他电脑需先下载相应 Skill，再从设置导入；已导入的副本可以独立于源目录使用。

该接口采用 [Chat Completions 请求格式](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。接入真实服务前需自行配置服务、模型和密钥；验收使用隔离的本机模拟服务，不消耗真实模型额度。

## 安装与升级

Linux 安装器将版本保存在 `~/.local/share/writer-desk/app/versions/`（设置 XDG_DATA_HOME 时遵循该目录），使用固定启动器与 `current` 链接。应用数据目录独立，升级不移动个人作品。

下载升级包及同名 `.sha256` 校验文件，放在同一文件夹。在「设置 → 安装与升级 → 安装升级包」选择 `.tar.gz`，程序会校验外部 SHA-256、内部清单、平台与文件路径。准备好后点击「重启完成升级」，当前内容成功保存才会退出。新版本启动完成后才激活固定入口；无法启动时保留原版本入口。

## 范围与文件

这一版是本地个人写作程序，没有账号、云端同步、多人协作或 DOCX 排版。单章最多 500 万字符，单部作品总大小上限 25 MiB，完整备份导入上限 50 MiB。

首次启动默认带有十万字长篇《潮汐档案馆》，另有《雾港来信 · 示例》和短篇《雨停之前 · 示例》。打开书架即可展示完整小说的大纲、人物分图与正文跳转；示例都可编辑，也可以新建自己的作品。默认补入只执行一次，不会因重启反复生成副本。

- `server.py`：本机服务与 SQLite 保存。
- `protection.py`：本机快照、保留与安全恢复。
- `ai_service.py`：显式调用兼容模型服务及结果校验。
- `skills.py`：本机写作规则导入、任务参考选择与上下文。
- `public/`：界面与交互代码。
- `start.sh` / `start.bat`：启动程序。
- `data/`：运行后自动生成的本机数据，分发压缩包不含此目录。

源代码采用 MIT 许可证。你写的正文与资料归你所有，不会因为程序开源而公开。

## 开发验证

运行 `python3 tests/verify_api.py`（Windows 可用 `py -3 tests/verify_api.py`）。检查会使用临时数据库和临时端口，不修改你的作品，覆盖保存、无章节策划、长短篇分类、封面验证、分卷及人物字段、关联校验、旧版升级、v1/v2/v3 备份往返、大小边界与并发冲突。

若已安装 Node.js，可运行 `node tests/story-analysis.test.js`，检查姓名与别名匹配、歧义称呼、回收过滤、同章索引、候选人名和长文本分析。

完整示例生成后可运行 `python3 tests/verify_sample.py` 与 `node tests/sample-analysis.test.js`，验证十万字作品的结构、关联、导入保存和人物分析；`node tests/i18n.test.js` 验证语言切换不会翻译作品内容。

默认演示库可运行 `python3 tests/verify_default_demo.py`，检查首次入库、旧库升级、改名编辑保留、并发启动与重启不重复。

作品文件夹可运行 `python3 tests/verify_book_folders.py`、`node tests/book-folder-ui.test.js` 与 `node scripts/test-desktop.cjs`，检查真实文件内容、保存一致性、文件保护及桌面桥接。

新版分类和布局可运行 `python3 tests/verify_categories.py`、`node tests/atlas-layout.test.js`、`node tests/atlas-ui.test.js` 与 `node tests/outline-ui.test.js`。Dagre 及其依赖离线打包，许可证见 `public/vendor/`。

完整写作流程可运行 `python3 tests/verify_workflow.py`、`node tests/workflow-outline.test.js` 和 `node tests/workflow-characters.test.js`，使用隔离数据和十万字示例验证目录补建、保存失败重试、分类索引、回收恢复、备份与重启。

新增功能验收可运行 `python3 tests/verify_protection.py`、`python3 tests/verify_ai.py`、`node tests/continuation-ui.test.js` 和 `node scripts/test-desktop.cjs`；均使用隔离数据。

本机 Skill 可运行 `python3 tests/verify_skills.py` 和 `node tests/ai-ui.test.js`，验证导入副本、任务参考、上下文计数及界面流程。

整部作品回收可运行 `python3 tests/verify_book_trash.py` 与 `node tests/book-trash-ui.test.js`，验证恢复完整性、版本冲突、旧窗口草稿、彻底删除、30 天到期边界、快照清理和示例不自动补回。
