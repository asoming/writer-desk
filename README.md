# 作家工作台 · Writer’s Desk

个人使用的中文写作程序。长篇与短篇分别管理，可以同时创作多部作品；每本书都有自己的封面、大纲、人物脉络图与正文。无需注册或联网，暂不接 AI。


桌面版采用独立窗口，Linux 已提供可直接运行的发行包。解压后运行 `writer-desk`，无需另外安装 Python；`install-linux.sh` 可注册应用菜单入口。Windows / macOS 提供构建配置，需在对应系统构建，当前未验证其安装包。

左下角「界面语言」可切换中文和 English，切换前自动保存当前作品。只翻译界面，书名、正文、大纲和人物资料保持原文。

点击书架的「载入长篇示例」可载入原创群像小说《潮汐档案馆》的可编辑副本，含六卷三十六章和三十二位人物。完整字数与验证结果见 `docs/acceptance-report.md`。

桌面端数据库位于系统应用数据目录 `WriterDesk` 下，程序更新不会把作品写入安装目录；本地网页版仍使用应用目录 `data/`。保留旧版 `data/` 在源码旁首次运行可复制旧库，原文件保留。开发与打包说明见 `desktop/BUILD.md`。

## 网页版启动

需要 Python 3.9 或更新版本，无需安装其他依赖。

- Linux / macOS：在解压后的 `yejian` 目录运行 `bash start.sh`。
- Windows：安装 Python 后双击 `start.bat`。支持 `py` 启动器，也支持已加入 PATH 的 `python`。
- 也可以运行 `python3 server.py --open`，然后打开终端显示的本机地址。默认地址为 `http://127.0.0.1:8765/`。

启动后保持终端窗口开启。退出前确认右上角显示「已保存到本机」，再在终端按 Ctrl+C。服务仅监听本机地址。

如果端口被占用，可以运行 `python3 server.py --port 8766 --open`，或 `bash start.sh --port 8766`。Windows 可在命令提示符中运行 `start.bat --port 8766`。换端口仍使用同一数据库。

## 书架与写作

书架分为长篇和短篇，均以封面与书名展示作品，并显示卷章数、字数、大纲数、人物数和最近编辑时间。可上传 PNG、JPG 或 WebP 封面，也可使用带书名的文字封面；图片只保存在本机。通过「封面与书名」修改作品信息。

点击「新建长篇 / 新建短篇」后，先进入这部作品的大纲。新作品可以暂时没有正文章节，先整理故事、人物与分卷构思，再开始正文。书架上的「大纲」「人物脉络」「开始正文 / 继续写作」分别打开该作品的相应页面；左侧的大纲库、人物档案库和长短篇写作入口也可以先选书。页面中的作品切换框可切换当前作品，各书的数据相互独立。

长篇按照「卷 → 章节」组织目录。卷可展开或收起；目录搜索会同时查找章节标题和正文。可编辑卷名与分卷说明、调整卷的顺序，并在卷下新建章节；章节也可以移到另一卷，或暂时保留为未分卷。回收卷前需先移走其中的活动章节。短篇不设分卷，可以写在单个正文篇章中，也可以拆成多个篇章。

正文使用纯文本，支持中文输入法和浏览器原生撤销、重做。停止输入约 0.65 秒后自动保存；Ctrl+S / Command+S 立即保存。可以新建、改名和调整章节顺序，收起目录、打开关联与资料，或进入专注模式。Esc 退出专注模式。

字数包含标点和英文字母，不计空格、换行；正文字号可在 16–26 px 之间调整。

## 大纲、人物与正文跳转

跳转方式参考「从这里开始」式入口，保留同一作品上下文，以具体章节为定位单位。

1. 先选定作品，在「大纲」整理全书总纲、分卷大纲、章节大纲和情节 / 设定节点。可以添加子节点、调整层级和顺序，并设置所属卷。
2. 长篇可用「生成卷章目录」按分卷大纲与章节大纲建立卷和空白章节，也可从单条章纲创建正文。大纲内容继续保留为策划，不会填入空白正文；已有的卷章与正文会保留，已关联的目录不会重复创建。「完整阅读」按当前层级连续展示整本书的大纲，可返回编辑某一节。
3. 在「人物脉络」添加人物、填写档案，再建立两个人物之间的关系。点击图中的人物会选中档案，点击连线会打开关系详情；搜索框可以查找人物。
4. 大纲节点、人物档案和关系详情中的「关联章节」可以连接多个正文章节。点击关联章节即可进入正文。
5. 正文上方的「关联大纲 / 人物」也可以建立关联。「关联与资料」侧栏显示本章的大纲、人物与关系，点击可返回相应页面并选中该条目。
6. 从大纲或人物图进入正文后，可点击「返回大纲 / 返回人物脉络」。

关联使用固定章节编号，因此改名和排序后仍然有效。当前版本定位到章节，不追踪正文中的某一个段落。移入回收站的章节不能直接打开，恢复后原关联重新可用。

人物图与人物资料共用数据，改名会同步。人物关系弹窗中的文字与人物选择也会自动保存。人物、地点、世界观和灵感资料可在写作侧栏编辑。

## 人物档案与正文提及

人物档案可填写姓名、别名与正文称呼、人物介绍，以及创作档案中的分组、身份与定位、愿望与目标、矛盾与弱点、最终去向。长篇还可按卷记录人物变化与关键行动，形成分卷人物弧线。关系由你编写名称、类型、阶段、说明及关联卷和章节。

登记人物姓名与别名后，程序按这些称呼匹配本书未回收章节的正文，生成「正文自动提及」索引；两个人物在同一章被提及时，会显示「同章提及」线索。索引随正文修改更新，可从关联章节跳转阅读。提及可能来自回忆、对白或转述，不代表人物实际出场；同章提及也不表示友谊、亲属、冲突或其他已确认关系。图中的实线表示手动编写的关系，虚线表示同章提及。

「从正文识别人名」用本地规则寻找部分“姓名＋动作”的写法，展示待确认候选与正文片段。它可能漏认或误认，需要你检查、修改并确认后才会建立人物档案。此功能不调用 AI，也不推断人物关系、心理或故事因果；仍可直接手动建立人物。

人物较多时默认显示当前人物和直接关系，可切换为全部人物。「显示同章提及」单独控制自动线索，完整关系索引仍可查看。人物搜索支持姓名、别名和分组。人物图支持放大、缩小、适应图幅，以及拖动空白区域平移。可按卷、人物分组筛选，或只看当前人物及其直接关系。下方「全部关系索引」提供关系搜索和类型筛选，便于从较大的关系图中找到具体条目。

## 保存、导出与恢复

默认数据库位于应用目录下的 `data/writer.sqlite3`，没有云端同步。

「导出与备份」提供以下选项。

- TXT / Markdown 正文，只包含未移入回收站的正文章节。
- 完整 JSON 备份，包含当前作品的分类、封面、分卷及说明、章节所属卷、大纲层级与类型、人物别名与创作档案、分卷人物弧线、人物关系类型与阶段、卷章关联和回收站。
- 恢复备份，创建一部新作品，不覆盖已有作品。新版导出 v3 备份，同时兼容早期 v1、v2 备份；未记录作品分类的旧备份默认为长篇。旧长篇会补齐默认卷并保留原章节与正文，恢复时会更新新作品的卷编号及相关引用。

一份 JSON 备份只包含当前作品。请定期复制备份到其他磁盘。移动整个程序时，先关闭服务，再复制整套应用与 `data` 目录；服务运行时不要只复制 SQLite 主文件，因为近期写入可能仍在 WAL 文件中。

浏览器会尽力缓存未完成的输入，便于异常关闭后恢复草稿。该临时缓存不代替数据库和独立备份。清理浏览器数据不会删除已经确认写入数据库的作品。

保存失败时会显示错误，并保留本页内容，可重试保存或下载本页备份。同时打开两个窗口编辑同一作品时，程序会检测版本冲突，允许把本页内容另存为新作品，避免直接覆盖另一个窗口。

卷、章节、大纲节点、人物资料和人物关系可移入回收站，再从回收站恢复；允许将最后一个正文章节移入回收站，继续保留大纲和人物策划。不提供永久删除按钮。

## 范围与文件

这一版是本地个人写作程序，没有账号、云端同步、多人协作、AI 或 DOCX 排版。单章最多 500 万字符，单部作品总大小上限 25 MiB，完整备份导入上限 50 MiB。

首次启动会创建各一部明确标注的虚构长篇与短篇示例。示例用于演示大纲、人物图与正文跳转，可以通过书架新建自己的作品。

- `server.py`：本机服务与 SQLite 保存。
- `public/`：界面与交互代码。
- `start.sh` / `start.bat`：启动程序。
- `data/`：运行后自动生成的本机数据，分发压缩包不含此目录。

源代码采用 MIT 许可证。你写的正文与资料归你所有，不会因为程序开源而公开。

## 开发验证

运行 `python3 tests/verify_api.py`（Windows 可用 `py -3 tests/verify_api.py`）。检查会使用临时数据库和临时端口，不修改你的作品，覆盖保存、无章节策划、长短篇分类、封面验证、分卷及人物字段、关联校验、旧版升级、v1/v2/v3 备份往返、大小边界与并发冲突。

若已安装 Node.js，可运行 `node tests/story-analysis.test.js`，检查姓名与别名匹配、歧义称呼、回收过滤、同章索引、候选人名和长文本分析。
