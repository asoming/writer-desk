## 保存与数据边界

### 章节整理、分屏与搜索

章节结构调整先经过保存检查，在保存期间输入发生变化时拒绝使用旧计划。拆分按编辑器 UTF-16 选区处理 emoji，合并完整保留原文，源章节进入历史回收。大纲、人物与段落记录随结构维护关联。最终保存失败时保留当前修改草稿，不重复应用结构操作。

双稿第二编辑器使用同一作品的章节模型与保存路径，保留原生撤销、输入法组字和各自滚动位置；输入法组字期间不关闭或切换编辑器。跨书搜索为本机字面匹配，排除已回收作品与内容，不将搜索文本发送给 AI。

### 外部备份与素材

外部备份只管理目标目录内带所有权标识的本工作台专有子目录，不覆盖或删除用户手动文件及其他书库的目录。目标盘离线不会阻止本机保存。彻底删除需要清理离线盘时保留持久待处理记录，重新连接后重试；待清理完成前不能声称所有外部副本均已删除。

素材单文件上限 5 MiB、总二进制上限 15 MiB、最多 120 项，同时受整书 25 MiB 限制。图片与 PDF 内容随完整 v4 JSON 备份迁移；v1–v3 仍可导入。网页摘录由作者填写来源与文字，程序不自动抓取或执行网页，也不对 PDF 做 OCR。导出正文和排版文档不包含整个素材库。

本地校对仍是有限确定性规则。新的语句和指代提醒供作者判断，不自动改写，不代表完整语义分析或人工校对。

### AI 配置与用量

旧单服务配置可继续读取，不会因读取而改写文件；首次保存纳入多配置结构。各服务密钥独立，本机文件权限受限，接口仅返回是否保存密钥。模型读取、设置保存、服务切换和聊天请求保留各自来源，迟到响应不能改到另一部书。

用量只取提供商实际返回的输入、输出、总 Token 与可选缓存 Token，耗时取本机请求时长。每百万 Token 单价和币种由作者填写；缺少必要用量或单价时显示不可用。不同币种分别汇总。流式连接中断不把缺失用量记成零，也不为获得用量重复付费请求。兼容服务可选择发送 `stream_options.include_usage`，不支持时保持关闭。

用量记录最多保留 20,000 条，界面显示最近 500 条，统计包含保留的全部记录。记录不含提示词、回复、正文、服务地址或密钥，存于本机 `ai-usage.sqlite3`，不写入作品 JSON、普通逐书备份或源码发行包。

### 排版与更新

模板验证字体白名单与数值范围，支持 A4、A5、Letter 和安全范围内的自定义纸张、四边页边距、字号、行距、缩进、段距、标题字号 / 对齐 / 加粗 / 分页。模板不接受任意 HTML、CSS 或脚本。封面与目录沿用既有导出路径。PDF 桌面桥只接受布局参数，输出到系统选择器确认的位置。

联网更新只读取固定 GitHub 仓库与当前平台 / 架构的发行文件，验证对应 SHA256 文件及精确文件名；下载后保存绑定版本、平台、大小和摘要的本机凭据，安装前再校验。不允许降级，不接收渲染进程指定的任意 URL、路径或命令。取消清理本次未完成文件；校验失败不安装。自动检查可关闭，自动下载默认关闭，不自动退出写作窗口。

Linux 托管安装沿用发行清单校验与保存后重启激活；DEB 使用系统安装器。Windows 受控后台助手等待旧进程正常退出，再重新校验 SHA256 后启动固定安装器。macOS 验证匹配架构的 DMG 后打开原生安装指引；当前未配置 Apple 公证，不宣称自动替换或绕过系统安全检查。

### 自建同步与手机

桌面和手机各自先保存在本机，自建 Hub 使用修订号和三方合并。不同章节、字段或明确分离的正文改动可合并；不确定的同处编辑保留两个原稿并进入冲突处理。所有者、可编辑和只读权限分开，一次性邀请可撤销。当前使用周期同步，不提供逐键共同光标。

普通局域网 HTTP 可在线写作，手机 PWA 的安装和离线启动需要可信 HTTPS；本机 `localhost` 安全上下文也支持离线缓存。手机离线稿件保留在 IndexedDB，联网后重试同步。服务端彻底删除清理历史与冲突并保留 ID 墓碑；不能远程抹除已经离线或被撤销设备的本机副本。配置、容器与完整行为见[自建同步说明](self-host-sync.md)。

## 十万字示例检查

使用《潮汐档案馆》的隔离副本，共 101,506 个非空白字符、6 卷 36 章。仓库中的示例正文未因测试而改写。

- 章节模型回归核对拆分后原文拼接相同、合并后两章完整、跨卷移动与排序不丢正文，并检查既有关系与段落记录。
- 实际 Electron 第二编辑器检查原生中文 / emoji 输入、撤销、输入法组字、调整面板与窄窗口，另检查章节整理、素材和外部备份界面。
- 模板测试逐段核对 Word、EPUB 与 PDF 用 HTML 的全部示例原文，并验证自定义纸张、字体、行距、缩进和章标题样式。实际 PDF 打印与安装包路径另列在原生验收中。
- 自建服务与两个客户端检查完整示例往返、并发修改、冲突原稿、权限与删除；真实手机尺寸浏览器检查下载、离线 emoji 编辑、离线刷新和联网恢复同步。
- AI 只使用本机模拟提供商与假密钥，验证实际返回用量、缓存计费、未知值、流式中断及多配置隔离；没有将真实付费模型调用列为本轮已验证项。

## 回归中修复的问题

- 升级 v4 备份后，更新版本断言和示例默认 `assetLibrary` 的兼容期望，原正文与其他字段保持逐项核对。
- 全流程回归发现回收卷章会丢失伏笔和时间线的正文关联。后端规范化现保留存在的回收章节 / 人物 ID，前端关联选择也保留隐藏的回收关联；恢复后仍可跳转，永久清理才移除。新增纯模型、UI 和真实 HTTP 的回收 → 恢复 → 彻删回归。
- Electron 44 的 PDF 自定义 `pageSize` 单位为英寸，采用毫米除以 25.4，Letter 使用规范枚举。实际生产打印桥在隔离窗口导出 101,506 字 PDF，共 289 页、3,092,175 字节，首张实际尺寸为 510 × 708.95996 pt；Letter 为 612 × 792 pt。该检查验证页面尺寸和完整来源正文，不等同于逐页人工排版审校。

- 活动窗口每 3 秒及恢复前台时消费删除回执，清除本机旧草稿和 AI 对话缓存；精准去掉已删除内容，保留其他章节未保存输入、对象身份、撤销和滚动。仅证明远端只有删除变化时自动提升保存版本，其他并发变化继续保留草稿并提示冲突。
- 删除链补充检查手工冲突合并、同步服务迁移、数据库读快照占用和退出中的回调，防止已删章节复活、误报清理完成或关闭死锁。
- 本机最后一轮原生验收曾在第一条原生输入前提前关闭 Chromium target，未捕获退出原因；新增 renderer 退出诊断后，独立完整重跑通过。发行仍以每个平台最新 CI 的完整硬门槛为准。
