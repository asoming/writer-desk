# 作家工作台 0.4.1 验收记录

验收日期：2026-10-10。本次加入本机写作 Skill，使用隔离数据库、临时安装目录和仅监听本机的模拟 AI 服务验证。未调用外部模型。上一版备份、历史恢复及升级验收见 `acceptance-0.4.0.md`；十万字写作流程见 `acceptance-0.3.6.md`。

## 本次完成

- 「设置 → 写作 Skill」导入和刷新本机的 `chinese-novelist`、`novelskill`、`human-writing`，查看只读规则及 Markdown 参考，保存默认选择。
- AI 对话框可临时选择多个 Skill 或取消全部，选择章节、续写、润色、大纲、人物或检查任务。自动模式随当前操作选择相关参考。
- 资料预览列出实际使用的参考文件和 Skill 字符数，所有规则计入上下文限制；只有点击发送才会调用已配置的服务。
- 原始 Skill 文件保持不变；导入副本、默认选择和个人数据不进入作品备份、GitHub 或发行包。其他电脑需要先下载相应 Skill，再导入。
- 设置与 AI 对话框中的新增入口均支持中英文，默认收起。默认不勾选任何 Skill，AI 仍需自行配置并启用。

Skill 作为规则与参考提供给模型，不执行其中的脚本，也不创建外部小说项目。当前用户要求、结果 JSON 结构和正文逐字证据校验仍优先，AI 结果继续先审阅再采用。

## 十万字示例与实际界面

《潮汐档案馆》保持原始内容：101,506 个非空白字符，6 卷、36 章、32 位人物、49 条大纲、6 个主题分图、35 条手动关系。

在实际界面导入三个本机 Skill，查看规则和参考文件，保存默认选择，再打开 AI 对话框验证继承、临时取消全部、任务切换和资料预览。选择 `novelskill` 与 `human-writing` 的润色任务后，预览与本机模拟服务实际收到的上下文均为 98,990 字符，包含 16,603 字符的 Skill 原文；取消两项后为 80,849 字符。

本次润色请求只加载两个主规则及 `小说-润色.md`、`fiction.md`、`revision.md`。模拟服务核对实际请求的 Skill、任务与参考路径，返回明确标记的测试建议。关闭结果窗口且未采用，原小说仍为 36 章。未测试真实模型的文学质量或判断准确率。

实际切换 English 后，Skill 名称、短介绍、状态、任务和按钮均显示英文；中文作品保持原文。验收截图见 `skills-v0.4.1.png`。

使用这一完整发行包在隔离目录完成升级准备、重启计划、真实原生窗口加载和加载成功后的固定入口激活。`PATH=/nonexistent` 时仍可离线启动；渲染进程沙箱、默认十万字示例及关闭后的子服务清理均通过。冻结后端可以列出三个 Skill，在首次导入前不创建副本或设置文件。
