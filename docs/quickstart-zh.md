# 快速上手 · 作家工作台 0.6.0

作家工作台是本地小说写作 App。长篇按卷章组织，短篇直接编辑一篇连续正文。写作、保存、备份和本地策划无需联网；AI 按需配置。

[使用指南](user-guide-zh.md) · [下载](https://github.com/asoming/writer-desk/releases) · [本轮验收](acceptance-v0.6.0.md)

## 安装与启动

0.6.0 源码功能已实现，本轮安装包等待四平台原生 CI 验收。请以发行页实际提供的版本为准，上一版安装包不含本轮全部功能。

| 系统 | 0.6.0 构建目标 | 安装方式 |
| --- | --- | --- |
| Ubuntu 22.04+ / 兼容 Debian 桌面，x64 | `WriterDesk-0.6.0-linux-amd64.deb` | 使用系统软件安装器，或 `sudo apt install ./WriterDesk-0.6.0-linux-amd64.deb` |
| Windows 10 / 11，x64 | `WriterDesk-0.6.0-windows-x64.exe` | 运行安装向导 |
| macOS 13+，Apple 芯片 | `WriterDesk-0.6.0-mac-arm64.dmg` | 将 App 拖入 Applications |
| macOS 13+，Intel | `WriterDesk-0.6.0-mac-x64.dmg` | 将 App 拖入 Applications |

桌面包包含运行环境，无需另外安装 Python 或 Node.js。升级前保存并正常退出旧版，安装后从固定应用入口打开，在「设置 → 关于」确认版本。个人作品保存在用户数据目录，独立于安装目录。

Linux 压缩包用户的升级入口与 DEB 不同；旧菜单入口可能仍优先打开旧版，详见[安装与旧图标迁移](../desktop/BUILD.md#run-a-linux-release)。签名、公证及 Mac 实机检查边界见[发行说明](distribution-checklist.md)。

## 用十万字示例检查功能

首次启动的长篇书架包含《潮汐档案馆》：101,506 个非空白字符、6 卷 36 章、32 位人物、49 个大纲节点、6 个主题分图、35 条手动关系。0.6.0 还包含 12 条伏笔和 18 个故事事件。

1. 点击书名或封面进入「写作」，从目录打开任一章；长篇目录可折叠分卷，章名可在目录或正文标题处修改，两处同步。
2. 打开「大纲」与「人物脉络」，点击关联章节跳转正文，再通过返回入口回到原条目。切换另一本书请返回书架。
3. 点击写作工具栏的放大镜，或按 `Ctrl / Command + Shift + F / H`，输入查找文字和替换文字。先检查预览，勾选要操作的章节，再执行替换；点击匹配片段可定位原文。
4. 点击「创作工具」，分别查看伏笔、时间线和写作统计。伏笔默认显示未回收项，时间事件可上下调整顺序，每项都能关联本书人物与正文。
5. 修改一段正文，停止输入约 0.65 秒自动保存，也可按 `Ctrl+S / Command+S`。输入和保存应保持当前阅读位置。
6. 打开左下角「历史记录 → 历史版本与差异对比」，选择旧版本、预览章节，点「对比当前稿」。红色是旧稿、绿色是当前稿；勾选段落后可单独恢复，其他段落保留当前稿。
7. 返回书架，从该书的「导出与备份」保存完整 JSON；也可用「排版导出」生成 Word、EPUB 或 PDF。JSON 用于继续编辑和迁移，排版文件用于阅读与分享。

示例可自由修改。升级与重启不覆盖作者改动；已有示例缺少新策划时，在书架点击「载入长篇示例」建立新版独立副本。回收或删除的示例不会因重启反复补入。正文可直接阅读[示例小说](../examples/潮汐档案馆.txt)。

## 创作工具

「创作工具」在大纲和写作工具栏中，始终属于当前作品。

- **伏笔追踪：**记录名称、说明、埋下 / 推进 / 回收状态，关联人物和正文；使用「未回收」筛选检查尚未闭合的线索。
- **故事时间线：**自由填写故事时间，例如「第三日清晨」或「帝国历 120 年」。用上移 / 下移明确事件顺序，程序不猜测虚构历法。
- **写作统计：**设置每日目标，查看近 90 天日历与 7 / 30 天趋势。按本机日期记录成功保存后的正文正增量；导入、章节恢复、整版和逐段恢复不计产量。字数包括标点，排除空格和换行。

伏笔、时间线、每日目标和保存过的长篇记忆进入完整 JSON 备份；活动统计保存在本机数据库，不随逐书 JSON 迁移。

## AI 与长篇记忆

在「设置 → AI 服务」填写兼容 Chat Completions 的基础地址、密钥及模型，启用后使用右侧对话栏。可读取模型列表；服务不支持列表时可手动填写。

- 在底部写提示词，点击发送或按 Enter；Shift+Enter 换行。预设提示词可修改，也可自由对话。
- 回复逐步显示，点「停止等待」结束当前请求。未完成的回复不会自动写进正文；完整候选仍需明确采用。
- 「资料 → 长篇记忆」提供本地自动摘录的章节摘要、人物最近提及及设定片段，可自行修订。续写时自动选取相关前文记忆，已勾选正文仍完整发送。
- 需要模型整理时，选择「整理长篇记忆」任务并勾选正文。候选经作者检查、编辑和确认后保存；正文改变后旧摘要会标记过期，不当作当前事实继续使用。
- 底部「＋」或粘贴可添加图片。识图需要视觉模型，封面生成需要服务支持 Images API。

普通写作、统计与本地记忆摘录不调用 AI。密钥、聊天记录、图片和本机 Skill 不进入作品 JSON。完整行为及限制见[AI 辅助](user-guide-zh.md#ai-辅助)。

## 保存、恢复与删除

- 「设置 → 关于 → 本机数据目录」查看实际保存位置。迁移作品优先使用逐书完整 JSON；导入会新建作品，不覆盖原书。
- 「设置 → 保存」调整自动备份。默认成功保存后每 5 分钟生成快照，每书保留 20 份；逐书「导出与备份 → 历史与自动备份」可预览与恢复。
- 书架「打开文件夹」为该书生成 `正文.txt` 与 `作品.yejian.json`，此后随成功保存同步；外部修改过的文件不会自动覆盖或导入。
- 整书回收保留 30 天，可恢复或确认彻底删除；App 关闭期间到期的，下次启动清理。删除章节在「历史记录」查看时间、预览、恢复或彻底删除。
- 彻底删除清理 App 管理的相应副本，自行导出与系统备份不在清理范围。重要作品的完整 JSON 请另存其他磁盘。

## 外观与操作

保存状态左侧的太阳 / 月亮图标切换白天和黑夜。「设置 → 通用」切换中英文并开启护眼模式；设置只影响界面，不翻译正文。

正文工具栏的「作品大纲」提供世界观、角色、剧情和故事梗概侧栏，提示由滚轮手动浏览，输入后消失。目录、正文及 AI / 资料之间的边界可拖动，双击恢复默认。

Mac 支持双指滚动、人物图平移和捏合缩放；非编辑区横向返回与 `Command + [` 先保存，再返回书架。实体触控板手感仍需 Mac 实机确认。
