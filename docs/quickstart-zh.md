# 作家工作台 · Writer’s Desk

这是可离线运行的个人写作 App。当前交付 Linux x64 桌面版，白底、轻边框、少量蓝色，界面可切换中文和 English。

## 启动

解压 `WriterDesk-0.4.7-linux-x64.tar.gz`，运行解压目录中的 `writer-desk`。无需另装 Python 或 Node.js。需要 Ubuntu 22.04+ 或兼容环境、GTK 3 和图形桌面。运行 `install-linux.sh` 完成安装并添加固定的应用菜单入口。

Windows/macOS 的构建配置已放进源码，当前没有对应系统的安装包。

## 用示例试写

1. 启动后，长篇书架已默认带有《潮汐档案馆》，无需手动载入。
2. 打开《潮汐档案馆》，查看六卷 36 章、32 位人物、49 条大纲节点、6 个主题分图和 35 条手动关系。
3. 从大纲或人物资料的关联章节打开正文，再通过「返回」回到原条目。
4. 尝试搜索正文、折叠分卷、修改内容和切换界面语言。停止输入后自动保存，也可按 Ctrl+S。
5. 从这本书右侧的「导出与备份」下载完整 JSON 备份。示例可以随意修改；如果需要一份原版，点击书架的「载入长篇示例」创建独立副本。

升级旧版时，会自动补入缺少的完整示例，原有作品及已修改的示例保留；重启不会重复生成默认示例。

正文共 101,506 个非空白字符，与 App 字数口径相同，包含标点。单独阅读文件为 `潮汐档案馆-完整示例小说.txt`。

## 保存位置

桌面 App 的作品写入系统用户数据目录，不写进安装目录。左下角「设置 → 本机数据目录 → 打开文件夹」可以查看实际位置。Linux 默认是 `~/.config/writer-desk/data/writer.sqlite3`。请使用完整 JSON 备份迁移作品。

左下角点击「设置」切换中文和 English。切换前会先保存当前作品，只翻译界面，书名、正文、大纲和人物内容保持原文。

桌面窗口不再显示系统标题栏和「文件 / 编辑 / 视图 / 帮助」菜单。现有 App 顶栏空白处可拖动窗口，右上角是最小化、最大化或还原和关闭。设置中可使用编辑命令、调整缩放、切换全屏、查看版本和数据目录、退出 App；回收站保留在左下角；导出与备份在各本书右侧。

每本书右侧的「打开文件夹」会打开该书的独立目录，含 `正文.txt` 和完整备份 `作品.yejian.json`。首次打开后，文件随 App 保存更新。书改名后目录仍保持，额外放入的资料保留；外部改动过的导出文件不会被覆盖，也不会自动写回 App。网页版会显示可复制的目录路径。

## 已保存到 GitHub

私有仓库：[asoming/writer-desk](https://github.com/asoming/writer-desk)。源码、小说和验收文档已经纳入版本管理；运行时产生的个人作品数据库和草稿不上传。

详细检验结果见源码中的 `docs/acceptance-report.md`。本版用十万字小说检查了从大纲构思、卷章生成、正文保存到备份恢复的完整流程，修复归卷、补建顺序、分类索引和失败重试问题。

## 书架、人物图与大纲

- 切换作品请返回书架，再点击另一部作品的封面；长篇和短篇分别选择。左侧大纲、人物脉络和写作进入当前作品，不再使用作品下拉框。
- 点击每本书右侧的「封面与书名」在书架上编辑。书名右侧骰子可离线取名；十款封面模板可选，也可上传图片。模板随书名更新，保存后生效。
- 每本书右侧的「移入回收站」可删除整部作品；正文与资料在回收站保留 30 天，可从左下角「回收站」恢复或确认彻底删除。满 30 天自动清理，App 关闭时到期的下次启动清理；彻底删除同时清理该书历史和本机自动备份，另行导出的文件保留。删空书架后重启不会再补入示例。
- 界面删除重复作品卡、统计栏和操作说明，保留书名、必要工具和保存状态。
- 人物图上方是主题分图，中间是彩色人物分组，图内可另按卷、关系类型筛选。同一人物可以属于多个主题分图。
- 点击「新建分图」，填写名称、说明并选择成员，保存后该分图只属于当前作品。默认先阅读档案，需要修改时点击「编辑人物」。
- 大纲按故事主线、世界设定、人物设定、分卷剧情、伏笔回收等主题分类，也可以输入自己的分类名称。分类、层级和卷可以组合筛选。
- 「完整阅读」是一篇连续文档，点击目录文字定位段落，点击正文标题编辑该节，关联章节也是文字链接。分类、层级和卷筛选默认收起；从正文返回大纲会定位原条目。
- 已修改的示例保持原内容；如需一份带六张分图和八类完整策划的原版，可从书架再次载入独立副本。

本机原有图标使用固定启动入口，本次已切换到 0.4.7，退出后重新打开即可；可在「设置」查看版本号。其他电脑安装时，解压后运行其中的 `install-linux.sh`。后续下载新版压缩包和同名 `.sha256`，可在「设置 → 安装与升级」选择升级包，并在保存后重启完成升级。旧作品保存在系统用户数据目录，可继续打开；下载压缩包本身不会替换旧的解压目录。

## 自动备份与历史恢复

「设置 → 数据保护」默认启用自动备份。成功保存后按间隔生成快照，默认每 5 分钟、每本书保留 20 份；需要时点「立即备份」。从各本书右侧的「导出与备份 → 历史与自动备份」先预览该书的旧版本，再恢复。恢复前保留当前版本，可以再次恢复回来。独立快照在本机数据目录的 `backups/` 中，建议另存到其他磁盘。

## AI 辅助

在「设置 → AI 辅助」填写兼容 Chat Completions 的 API 基础地址、模型名称和密钥，再启用。密钥只存在本机，不放进作品备份或 GitHub。

大纲和写作页右侧是 AI 对话栏。在底部填写提示词，点击右侧发送；Enter 发送、Shift+Enter 换行。可以边聊天边编辑，收起后点击「AI 辅助」重新打开。自由讨论构思，或选择预设任务；预设提示词可修改、恢复，后续追问会带上本段对话前文。资料和写作 Skill 在折叠区中选择。

每本书的大纲和写作对话分别保存在本机，重开 App 和切换语言后仍能接着聊；「新对话」可清空当前交流。作品 JSON 备份不包含对话记录。生成的大纲、草稿与人物关系先在消息中预览，点击采用才写入；保存失败可以重试，不会重复追加。空白新书可先生成大纲，确认后再建立卷章。人物页仍用独立预览窗口。

「封面与书名」中的 AI 可先生成候选名字和封面提示词。在 AI 设置填入同一服务支持的图像模型，再点击「生成封面」请求图片，预览后采用；书名在本机排版。AI 返回不会自动改动作品。

## 使用已下载的写作 Skill

在「设置 → 写作 Skill」导入本机的 `chinese-novelist`、`novelskill`、`human-writing`。可以查看每个 Skill 的规则和参考文件，勾选并保存默认选择；AI 对话栏中也可临时调整。

选择章节、续写、润色、大纲、人物或检查任务后，程序会加载对应参考。发送前能看到使用了哪些 Skill、哪些文件及总字符数。原 Skill 目录只读，副本保存在本机；源文件更新后可重新导入。Skill 不会独立运行或代替 AI 模型，需要先配置 AI 服务。导入副本不进入作品备份或 GitHub，也不随安装包分发。

AI 上下文默认为自动，由模型服务校验。App 不再使用固定 250,000 字符上限，也不自动截断资料。AI 设置的高级选项仍可启用手动字符保护。章节、对话历史与所选 Skill 均计入资料总数，详情收在「资料」中。
