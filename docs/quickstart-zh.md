# 作家工作台 · Writer’s Desk

这是可离线运行的个人写作 App。当前交付 Linux x64 桌面版，白底、轻边框、少量蓝色，界面可切换中文和 English。

## 启动

解压 `WriterDesk-0.4.0-linux-x64.tar.gz`，运行解压目录中的 `writer-desk`。无需另装 Python 或 Node.js。需要 Ubuntu 22.04+ 或兼容环境、GTK 3 和图形桌面。运行 `install-linux.sh` 完成安装并添加固定的应用菜单入口。

Windows/macOS 的构建配置已放进源码，当前没有对应系统的安装包。

## 用示例试写

1. 启动后，长篇书架已默认带有《潮汐档案馆》，无需手动载入。
2. 打开《潮汐档案馆》，查看六卷 36 章、32 位人物、49 条大纲节点、6 个主题分图和 35 条手动关系。
3. 从大纲或人物资料的关联章节打开正文，再通过「返回」回到原条目。
4. 尝试搜索正文、折叠分卷、修改内容和切换界面语言。停止输入后自动保存，也可按 Ctrl+S。
5. 在「导出与备份」下载完整 JSON 备份。示例可以随意修改；如果需要一份原版，点击书架的「载入长篇示例」创建独立副本。

升级旧版时，会自动补入缺少的完整示例，原有作品及已修改的示例保留；重启不会重复生成默认示例。

正文共 101,506 个非空白字符，与 App 字数口径相同，包含标点。单独阅读文件为 `潮汐档案馆-完整示例小说.txt`。

## 保存位置

桌面 App 的作品写入系统用户数据目录，不写进安装目录。左下角「设置 → 本机数据目录 → 打开文件夹」可以查看实际位置。Linux 默认是 `~/.config/writer-desk/data/writer.sqlite3`。请使用完整 JSON 备份迁移作品。

左下角点击「设置」切换中文和 English。切换前会先保存当前作品，只翻译界面，书名、正文、大纲和人物内容保持原文。

桌面窗口不再显示系统标题栏和「文件 / 编辑 / 视图 / 帮助」菜单。现有 App 顶栏空白处可拖动窗口，右上角是最小化、最大化或还原和关闭。设置中可使用编辑命令、调整缩放、切换全屏、查看版本和数据目录、退出 App；回收站和导出与备份仍在左下角原位。

每本书右侧的「打开文件夹」会打开该书的独立目录，含 `正文.txt` 和完整备份 `作品.yejian.json`。首次打开后，文件随 App 保存更新。书改名后目录仍保持，额外放入的资料保留；外部改动过的导出文件不会被覆盖，也不会自动写回 App。网页版会显示可复制的目录路径。

## 书架、人物图与大纲

- 切换作品请返回书架，再点击另一部作品的封面；长篇和短篇分别选择。左侧大纲、人物脉络和写作进入当前作品，不再使用作品下拉框。
- 点击每本书右侧的「封面与书名」会在书架上打开编辑框。保存或取消后仍停留在原书架，只修改该作品的封面和书名。
- 界面删除重复作品卡、统计栏和操作说明，保留书名、必要工具和保存状态。
- 人物图上方是主题分图，中间是彩色人物分组，图内可另按卷、关系类型筛选。同一人物可以属于多个主题分图。
- 点击「新建分图」，填写名称、说明并选择成员，保存后该分图只属于当前作品。默认先阅读档案，需要修改时点击「编辑人物」。
- 大纲按故事主线、世界设定、人物设定、分卷剧情、伏笔回收等主题分类，也可以输入自己的分类名称。分类、层级和卷可以组合筛选。
- 「完整阅读」是一篇连续文档，点击目录文字定位段落，点击正文标题编辑该节，关联章节也是文字链接。分类、层级和卷筛选默认收起；从正文返回大纲会定位原条目。
- 已修改的示例保持原内容；如需一份带六张分图和八类完整策划的原版，可从书架再次载入独立副本。

本机原有图标使用固定启动入口，本次已切换到 0.4.0，退出后重新打开即可；可在「设置」查看版本号。其他电脑安装时，解压后运行其中的 `install-linux.sh`。后续下载新版压缩包和同名 `.sha256`，可在「设置 → 安装与升级」选择升级包，并在保存后重启完成升级。旧作品保存在系统用户数据目录，可继续打开；下载压缩包本身不会替换旧的解压目录。

## 自动备份与历史恢复

「设置 → 数据保护」默认启用自动备份。成功保存后按间隔生成快照，默认每 5 分钟、每本书保留 20 份；需要时点「立即备份」。在「导出与备份 → 历史与自动备份」先预览旧版本，再恢复。恢复前保留当前版本，可以再次恢复回来。独立快照在本机数据目录的 `backups/` 中，建议另存到其他磁盘。

## AI 辅助

在「设置 → AI 辅助」填写兼容 Chat Completions 的 API 基础地址、模型名称和密钥，再启用。密钥只存在本机，不放进作品备份或 GitHub。

从大纲、人物脉络或正文点击 AI 入口，选择资料和任务。先检查资料数量和字数，点击发送后才会调用服务。可以提取候选人物与关系、根据大纲起草正文、检查一致性。结果先预览并由你确认，才加入作品。真实使用需配置自己的服务；本版已用本机模拟服务验证完整流程。
