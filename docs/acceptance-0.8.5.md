# 作家工作台 0.8.5 验收

## 本轮范围

Skill 详情按文章式弹窗阅读。顶部显示图标、名称和简介，右上角有滑动开关、更多菜单和关闭按钮，底部提供立即试用及适用时的删除或恢复操作。Markdown 显示标题、段落、列表、引用、代码与表格，隐藏 YAML 文件头；复制 Markdown 保留原始内容。主规则和参考资料可滚轮阅读，无常驻文件侧栏。

更多菜单支持打开编辑、在文件管理器中显示、复制原始 Markdown、导出和参考文件切换。文件管理器只打开 App 内置目录或已导入的本机副本；桌面仅接收 Skill ID，由后端定位并检查目录，拒绝任意路径与链接。浏览器环境隐藏文件管理器操作。

Skill 选择统一使用滑动开关。设置里的默认规则和任务自动保存，失败恢复原选择；对话里的选择继续用于当前会话。「立即试用」选择当前作品的 AI 对话规则，保留提示词和任务，不自动发送；没有作品时提示先从书架选择。

读取正文不调用 AI、不修改作品或规则。HTML 与脚本只显示为文字，远程图片不抓取；相对 Markdown 链接只能打开已知参考文件。文件有格式化节点预算，超出预算以文字显示。

叉号或 Esc 关闭后回到原设置位置；更多菜单打开时 Esc 先关闭菜单。关闭、切换设置、打开另一弹窗或保存期间切换内容时，迟到响应不会重开旧窗口或覆盖新窗口。支持中英文、夜间、护眼与窄窗口。
