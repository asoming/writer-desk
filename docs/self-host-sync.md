# 自建同步与手机写作

作家工作台的桌面稿件始终先保存到本机。自建同步是可选功能，手机端和其他电脑通过你自己的同步服务共享作品，不需要注册第三方账号。

## 在桌面启动

1. 打开设置中的 **同步与协作**。
2. 在自建同步服务中选择 **仅本机** 或 **局域网**，默认端口为 `8766`，点击启动。
3. 局域网使用时，让手机和电脑连接同一个可信网络，在手机浏览器打开面板显示的局域网地址。
4. 由空间所有者生成一次性邀请，选择可编辑或只读。其他设备填写邀请口令和姓名后加入。
5. 点击立即同步，或保留自动同步。桌面和手机默认每 15 秒检查一次。

“局域网”会读取电脑已启用网络接口上的 IPv4 地址，无需联网查询或依赖电脑名称解析。手机应打开实际连接 Wi-Fi 或有线网络的地址；`127.0.0.1` 只供电脑本机使用。如果电脑有 VPN、虚拟网卡等多个地址，选择与手机处于同一网络的那个。更换网络后重新打开同步面板，地址会刷新。

若系统暂时无法读取接口地址，可在电脑的网络设置中查看当前 Wi-Fi 或有线网络的 IPv4 地址，再在手机输入 `http://该地址:8766/mobile/`（使用自选端口时替换 `8766`）。纯 IPv6 网络暂不自动生成连接地址。

首次启动会创建本机所有者。关闭同步服务不会删除服务中的作品；再次启动会读取已有空间。邀请默认 24 小时有效、只能使用一次，所有者可以撤销未使用邀请和成员。撤销成员后，该设备保留已下载的本机文件，但不能继续读取或写入同步服务。

## 手机端

手机书架区分长篇和短篇。长篇按卷、章选择正文；短篇是单一正文。可以编辑正文、大纲和人物资料，大纲可跳转关联章节。修改先自动保存到浏览器 IndexedDB，再发送到同步服务。离线期间的待同步请求保存在本机，恢复连接后重试。

浏览器数据属于当前浏览器与站点。不要在未同步时清除站点数据或使用会自动清理数据的隐私窗口。手机已有稿件会保留在本机；切换到其他同步空间时，界面只展示当前空间的作品。

### HTTP、HTTPS 与安装

- `http://localhost`、`http://127.0.0.1` 在本机浏览器中属于安全上下文，可以注册离线缓存。
- `http://192.168.x.x` 等普通局域网地址可在线写作与本机自动保存，但手机浏览器不允许它注册 Service Worker，**不能依赖它离线启动或安装 PWA**。
- 手机安装和离线启动需要浏览器信任的 HTTPS。打开 HTTPS 手机页面并完成首次缓存后，可使用浏览器的“添加到主屏幕”或“安装应用”。iPhone/iPad 可通过 Safari 分享菜单添加到主屏幕。具体入口由浏览器决定。

首次离线缓存包含界面文件，不包含接口响应或令牌；稿件和登录凭据只存放在本机 IndexedDB。退出空间会移除活动登录信息，不会清空已缓存稿件。

## 独立启动服务

适合常开电脑、NAS 或自行管理的服务器。要求 Python 3.10 或更高版本，在仓库目录运行：

```sh
python3 collaboration.py --data-dir ./sync-data --host 127.0.0.1 --port 8766
```

允许局域网设备访问：

```sh
python3 collaboration.py --data-dir ./sync-data --host 0.0.0.0 --port 8766
```

第一次启动会在终端显示一次性初始化口令。在手机页面展开“初始化自建服务”，输入口令创建所有者。不要将初始化口令发给无关人员。初始化完成后，旧口令失效，服务重启不会重新开放初始化。

### 使用已有可信证书

```sh
python3 collaboration.py --data-dir ./sync-data --host 0.0.0.0 --port 8766 \
  --cert /path/to/fullchain.pem --key /path/to/privkey.pem
```

证书的域名必须与浏览器访问地址一致，设备必须信任证书颁发机构。程序不会自动安装根证书，不会关闭浏览器证书检查。

### 使用 Caddy 反向代理

服务只监听本机回环地址，由 Caddy 提供 HTTPS。拥有可解析到服务器的域名时，可以使用：

```caddyfile
writer.example.com {
    reverse_proxy 127.0.0.1:8766
}
```

域名、DNS、证书申请及网络开放由部署者管理。本机或局域网内部使用证书时，需要自行安排受信任证书及设备信任配置；本项目不修改这些系统设置。HTTP 上的邀请口令和稿件不会经过传输加密，请只在可信的本机或局域网使用。

## 多人编辑与冲突

每个空间的成员有所有者、可编辑、只读三种权限。只有所有者可以生成邀请、撤销成员。只读成员不能提交修改或解决冲突。

同步以服务端修订号为基准。不同章节、不同字段，以及能明确区分的正文片段修改会进行三方合并。两人修改同一处、同时删除和修改作品，或不同排序无法可靠合并时，服务保留基准、服务端版本和待同步版本。

冲突不会覆盖本机稿件。处理时可以选择保留服务端版本、将待同步稿件另存成独立作品，或在桌面手动合并正文后保存。处理期间出现新服务端修订，操作会被拒绝，需要重新查看最新版本。手机支持查看两个版本与另存副本。

正文中的段落批注与书签会随作品一起同步，手机编辑使用同一个锚点模型维护位置。作品附件随作品数据同步。删除作品通过回收状态传播，内容保留以便恢复；其他离线设备不能通过重试同一请求悄悄覆盖一个已更新版本。

## 数据与备份

- 独立服务的数据在 `--data-dir` 指定目录的 `collaboration.sqlite3` 中。
- 桌面内置服务的数据在桌面数据目录下的 `sync/hub/`，本机连接与同步基准在 `sync/desktop-sync.sqlite3`。
- 邀请和成员令牌在 Hub 数据库中只保存 SHA-256 摘要。桌面自己的访问令牌是调用服务所需的凭据，保存在权限为 `0600` 的本机文件中，不会从状态接口返回。
- 同步服务保留修订与冲突原稿。备份数据库时先停止服务，复制整个数据目录；或者使用 SQLite 的一致性备份工具。不要只复制一个正在写入的主数据库文件而遗漏 WAL。
- 停止内置服务后手机无法联网同步，已完成 HTTPS 离线缓存的手机仍可在本机写作。

同步服务没有公网发现、第三方云托管、用户邮件找回或付费依赖。请保留数据备份和所有者设备。对公网开放服务前，应自行配置 HTTPS、网络访问策略和系统备份。

### 彻底删除与离线设备

彻底删除作品或章节时，桌面会立即清理自身的同步基准、待发送副本，以及自己管理的本机 Hub 数据库，包括历史修订、冲突原稿和幂等响应里的正文。本机 Hub 即使没有启动，也会清理磁盘上的自有数据库。

其他同步服务暂时离线、凭据已撤销或当前账号只有只读权限时，清理要求进入持久队列，界面保留“清理尚未完成”。服务恢复且权限允许后自动重试。服务只保留已删书籍、章节的编号与删除记录，旧客户端上传、手动冲突合并和历史基准都不能恢复这些编号。同步接收清理记录时，会保留其他章节尚未同步的编辑。

这不等于远程擦除：已经离线、被撤销访问权限的设备，以及用户自己复制到 App 管理范围之外的文件，无法由同步服务强制删除。需要删除这些副本时，请在相应设备或备份位置处理。

## 容器部署

仓库提供 `Dockerfile.sync` 和 `compose.sync.yml`。运行：

```sh
docker compose -f compose.sync.yml up --build -d
docker compose -f compose.sync.yml logs writer-sync
```

默认仅将容器端口映射到宿主机 `127.0.0.1:8766`，适合由宿主机 HTTPS 反向代理访问。初始化口令见首次日志。要允许局域网 HTTP，按自己的网络环境修改端口绑定，并注意上述浏览器安全上下文限制。
