# 0.6.1 Linux 打包修正版验收记录

日期：2026-10-15。范围：Linux 最终发行清单、TAR 用户安装路径及相关回归。本轮重新执行四平台原生 CI，不以 0.6.0 的报告代替本轮结果。

## 问题来源

0.6.0 原生 CI 对 Linux DEB、Windows EXE 和两种 Mac DMG 的对应检查通过。发布后实际校验 Linux TAR 用户安装时，发现最终目录中的 `resources/apparmor-profile` 没有进入 `release-manifest.json`。该文件在 DEB 打包目标运行后加入，清单先于最终文件集合生成。

安装器在复制和启动入口切换之前拒绝了包，检查没有修改真实用户作品库或替换旧 App。0.6.0 发行说明已追加已知问题，原资产和校验值保持不变。修复采用新版本 0.6.1，旧版记录见 [0.6.0 验收](acceptance-v0.6.0.md)。

## 修复范围

- 在所有会修改发行目录的目标完成后，为最终文件集合生成清单，纳入 `resources/apparmor-profile`。
- 对最终发行目录、清单与 TAR 内容做一致性检查，覆盖后加入文件，不靠放宽校验绕过遗漏。
- 增加真实 TAR 用户安装回归，使用独立临时安装及数据根，检查包内安装脚本、托管安装完成及固定入口；该 TAR gate 不启动窗口，保存 / 重开由同轮 DEB 原生包和冻结服务检查覆盖。

八项写作功能、输入回顶修复、书籍格式及示例正文沿用 0.6.0；本轮没有调整故事内容或重写用户作品。

本机全部 36 个 Node 测试文件及 16 项发行收集回归通过。修复副本的检查确认旧发布资产保持原 SHA256，原始 TAR 被新检查拒绝；重新生成完整清单后通过包内安装脚本，所有安装路径均位于临时根，个人作品库保持不变。
