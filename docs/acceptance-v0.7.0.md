# 0.7.0 稿件导入、校对与批注验收记录

日期：2026-10-15。范围：本地稿件导入、本地规则校对、段落批注与书签，以及它们与保存、历史、备份和彻底删除的联动。

当前为 0.7.0 源码及候选版本。三个模块的定向测试、全部源码回归、冻结后端和便携书库检查已通过，36 章示例副本已完成真实 Chrome 关键交互；Electron 及四平台原生安装包检查仍在进行。当前已发布版本仍为 [0.6.1](https://github.com/asoming/writer-desk/releases/tag/v0.6.1)；本记录不代表 0.7.0 已经发布或安装完成。

## 功能入口与行为

| 功能 | 入口 | 已实现行为 |
| --- | --- | --- |
| 稿件导入 | 书架「导入稿件」 | 本机选择 DOCX、TXT、Markdown，预览后确认创建独立作品 |
| 本地校对 | 写作工具栏「校对与批注」图标 →「本地校对」 | 当前章 / 全书扫描、定位、选择确定错词修正、忽略和词典 |
| 添加批注 / 书签 | 同一图标 →「添加批注 / 添加书签」 | 关联正文选区，未选时关联当前非空段落 |
| 快捷添加 | 正文编辑框内 `Ctrl / Command + Shift + M / B` | 分别添加批注 / 书签，中文输入法组字期间不触发 |
| 记录管理 | 同一图标 →「批注 / 书签」 | 当前正文 / 全书列表、标题与说明、解决状态、跳转及重新关联 |

### 稿件导入

- 单文件上限 12 MiB，支持 `.docx`、`.txt`、`.md` 和 `.markdown`。解析及预览在本机完成，不写入已有书籍、不读取外部资源。
- 长篇支持自动识别、中文卷章标题、标题层级和不分章策略；纯文本支持自动识别、UTF-8、UTF-16 与 GB18030 编码。
- 预览显示卷章、字数与正文，可调整卷名和章名；文件、分章策略、编码、作品名称或类型变化后需要重新预览。
- 确认时重新解析原文件，核对 `sourceHash`，使用 `requestId` 和完整预览摘要在 SQLite 事务中绑定同一次确认。连接中断或并发重试只创建一部作品，内容变化不能复用原确认。
- 新书不覆盖原书，短篇为一篇连续正文。成功导入不增加当天写作产量。
- Word 仅导入正文、表格文字与标题结构，图片、Word 批注和排版不导入；不支持旧 `.doc`。应用内完整资料迁移仍使用逐书 JSON。

### 本地校对

- 20 组固定常见错词规则提供明确替换建议，用户逐条或批量勾选后应用，没有默认勾选或自动改稿。
- 部分重复功能词、重复标点、未闭合 / 未配对引号和括号、中文段落中的英文标点仅提示，不参与自动修正；拟声词、省略号等文学表达不作强制修改。
- 每书词典上限 500 项、单项 1–100 个 Unicode 字符，人物姓名及别名自动保护；完整提示必须位于保护词跨度内，单字重叠不会遮蔽整条错词。
- 全过程离线，不调用 AI 或网络。提示可定位准确 UTF-16 选区，也可忽略或加入词典。
- 应用前核对书籍、保存版本、来源正文与词典；保存失败保留当前修正草稿，旧预览立即失效，重试不重复应用。正常修正通过既有保存与历史版本路径。
- 结果最多展示 5,000 条，超出时提示缩小范围；容量检查在稿件变更前完成。

### 批注与书签

- 每类最多 5,000 条，单次原文关联最多 20,000 个 UTF-16 字符单位；保留创建 / 修改时间、引用、上下文与解决状态。
- 插入前文时调整锚点，改动引用内部文字时更新引用。删除或完整替换原文、相邻重复段落造成位置歧义时失效，不跳到其他相同句子；可手动重新关联。
- 回收章节保留记录，恢复后可继续使用。彻底删除清理关联原文和定位上下文，联动当前稿、历史和 App 自动备份；其他章节的批注保留。
- 旧短篇合并、恢复及彻删使用 UTF-16 偏移，处理 emoji 边界并避免重复位移。保存、输入法组字与历史恢复使用统一锚点更新路径。
- 完整 JSON 使用原有 v3 备份格式并携带 `reviewTools` 的词典、批注和书签；缺少该扩展字段的旧书使用空默认值。TXT、Markdown 和排版导出不携带这些编辑资料。

### 十万字示例

使用《潮汐档案馆》的隔离副本：101,506 个非空白字符、6 卷 36 章。验收没有改动仓库中的原示例正文。新版示例资料增加 6 个书签和 3 条批注，其中 1 条已解决，用于展示跳转、管理与解决状态；已存在的作者副本不被覆盖。

- 三种导入格式逐章核对完整正文，保留 6 卷 36 章和全部 101,506 字；导入后重开以及 JSON、历史、备份中的正文一致。
- 校对原示例得到 0 条规则内提示，原文保持不变。此结果只说明未命中当前有限规则，不等同于对文学稿的全面人工校对。
- 在隔离副本植入确定错词、重复词及未闭合标点，确认只修正勾选的确定项，词典保护与提示定位有效。
- 批注在 36 章逐章建立并做 JSON 往返，插入前文后核对引用与选区；重复文本、删除、完整替换及旧短篇恢复另有针对性回归。

## 验收边界

本地校对是有限规则集，不提供完整词典、语义校对或文学质量评分。导入预览用于确认识别结果，不能保证任意文档格式都能无损还原原排版。Word 图片、批注和格式不属于本轮导入范围。

用户自行导出的文件、系统备份与物理磁盘恢复痕迹不在 App 彻底删除范围；本轮检查 App 管理的书籍、历史及自动备份。实体 Mac 触控板、真实付费 AI、Word 实际渲染、Windows 发布者签名及 Apple 公证沿用此前验收边界，本轮没有新增这些验证结果。
