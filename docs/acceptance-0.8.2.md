# 作家工作台 0.8.2 验收

本轮新增默认首页与全库写作统计，调整对照修改入口及两栏布局，整理常用操作图标。所有数据测试均使用隔离书库；没有将真实用户稿件用于测试。

首页统计按当前书架中的活动作品汇总，回收的作品排除，恢复后重新纳入；彻底删除清理该书活动记录。连续与累计写作天数使用全历史，趋势与日历提供近 90 天。新首页目标仅写独立本机设置，不改每书正文、修订号或旧版逐书目标。

原生安装包工作流将对同一提交运行上述回归、冻结首页 API / 资源和实际安装器检查。当前记录仅确认源码和界面；最终安装包、提交号与本机安装结果在发行验收后补充。
