# 0.4.12 图片对话与提示词验收

日期：2026-10-12

## 交付

提示词框取消手动拉伸手柄，随输入、粘贴、预设切换、草稿恢复、发送清空和分栏宽度变化自动增高或收回。最大高度为 240px，并不超过对话面板高度的 30%；超过时在框内滚动，保留交流空间。

大纲与写作对话支持「＋」选图、粘贴图片、缩略图预览和移除。混合粘贴的文字交给原生文本框处理，保留文本与撤销行为。图片可以单独发送，用户图片和接口返回的图片均显示在对话中，点击打开独立大图，Esc、关闭按钮或点击外部关闭；关闭大图恢复被暂缓的候选结果。

每本书的图片原件在本机 `data/ai-chat-images/<bookID散列>/` 中独立保存，聊天偏好只记录小型引用。重开后原图与提示词仍可读取；作品回收保留图片，彻底删除和 30 天清理删除对应字节。源码、安装包和作品 JSON 备份不含对话图片。

## 协议与边界

只有显式发送调用已配置 AI。本机上传与预览不调用模型。发送采用 Chat Completions 的 text + image_url 内容数组；纯文字请求保持兼容。历史用户图片保留原角色，历史助手图片放到明确标注的只读参考资料中，助手文本保持原角色和内容。图片不按 Base64 长度计入文字上下文，另外显示图片数量。

单条最多 4 图，单图 8 MiB，一次请求含历史的原图总计 20 MiB。只接受验证后的 PNG、JPEG、WebP，本机文件名按内容散列，不信任上传路径、符号链接、文件扩展名或外部 URL。兼容服务的内容数组、message.images 及 JSON images 内联图片会保存并显示；无法显示的图片给出提示并保留合法文字。识图需要模型支持，未承诺所有文字模型能看图或生成图片。没有放宽 CSP 或自动下载远程图片。

官方格式参考：[OpenAI 图片消息文档](https://developers.openai.com/api/docs/guides/images-vision?api-mode=chat)。

## 验证

- 26 个 JavaScript／桌面脚本、17 个 Python 后端脚本全部通过，测试前后输入散列一致。其中聊天集成 41 项、图片界面 11 项、自动高度 5 项；后端图片对话 9 项、图片存储 4 项。
- 上传、纯图与混合粘贴、移除、在途切书、重试、不同图片的新轮次、等待期间保留下一条提示词与图片、重开、坏图和外链拒绝均有覆盖。中文输入、原有候选采用、保存和长短篇流程回归通过。
- 浏览器使用隔离示例书库与本机假 AI，实际上传并发送示例封面，双方图片可见，点击大图正常；长提示词增长到 227px 后滚动，普通多行提示词 155px，短提示词收回 44px，resize=none。重开后两张对话图片均从本机加载，原章节 2,860 字保持，控制台无错误。
- 发行压缩包与全部 31 个 public 文件、两项示例资源和 ASAR 主进程逐字节匹配；USTAR 归档不含个人数据或导入 Skill。安装包真实完成 0.4.11 → 0.4.12 隔离升级、原生启动和新入口激活，渲染沙箱开启，PATH=/nonexistent 可启动，完整示例仍为 101,506 字。
- 直接运行安装包中的 frozen writer-service，使用临时书库验证上传、读取、预览不联网、真实 image_url 发送到本机假provider、图片回复读取、重启后引用仍可读，作品内容不变。只发生 1 次本机假provider调用，没有真实AI调用。
