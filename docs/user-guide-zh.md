# 使用指南 · 作家工作台 0.8.3

本文说明书架、稿件导入、策划、写作、校对与批注、历史恢复、排版导出和 AI 辅助。首次使用请阅读[快速上手](quickstart-zh.md)；下载与开发入口见[项目首页](../README.md)。

适用版本：[0.8.3 测试版](https://github.com/asoming/writer-desk/releases/tag/v0.8.3)，新增人物主脉络、总脉络和成长轨迹，以及独立保存的同章对照稿。各平台构建与验收状态见[本轮验收记录](acceptance-0.8.3.md)。安装方式见[发行说明](distribution-checklist.md)与[桌面构建说明](../desktop/BUILD.md)。

## 首页与书架

每次启动默认打开「首页」，查看所有书架作品的今日新增、总字数、连续写作、趋势、日历和最近作品。点击最近作品继续写作，也可从左侧进入书架切换作品。常用操作使用图标，悬停可查看名称。

## 书架与作品

书架分为长篇和短篇，每部作品独立保存封面、正文、大纲、人物、伏笔和时间线。点击封面、书名或「继续写作」进入正文；书架上的大纲和人物按钮打开该书的对应页面。新建作品先进入大纲，方便先策划再动笔。切换另一部作品请返回书架，工作区不使用作品切换下拉框。

作品名称只在书架「封面与书名」修改。书名右侧骰子可离线随机取名；支持十款模板封面和 PNG、JPEG、WebP 上传，模板随书名更新。AI 生成书名和封面需要配置相应服务，候选经明确采用后生效。

「打开文件夹」先保存当前编辑，再打开该书的独立目录。首次生成 `正文.txt` 和 `作品.yejian.json`，以后随成功保存同步；目录按作品编号区分，同名书不共用目录，改书名不改变目录。额外文件保留，外部修改过的导出文件不会覆盖，也不会自动导入 App。浏览器版显示可复制的目录路径。

《潮汐档案馆》为 101,506 个非空白字符的原创示例，含 6 卷 36 章、32 位人物、49 个大纲节点、6 个主题分图、35 条手动关系、12 条伏笔和 18 个故事事件。0.7.0 新增 6 个书签及 3 条批注，其中 1 条已解决；这些示例资料不改动原正文或设定。已有示例的作者修改不被升级覆盖；需要新策划时，可在书架「载入长篇示例」创建独立副本。回收或删除的示例不会因重启反复补入。

## 导入已有稿件

在书架点击「导入稿件」，选择本机的 Word `.docx`、TXT 或 Markdown（`.md` / `.markdown`），单个文件最多 12 MiB。导入在本机解析，不上传文件，也不读取文档里的外部链接。

1. 选择长篇或短篇，可填写作品名称；留空时使用稿件标题或文件名。
2. 长篇可用「自动识别」「按第几卷、章识别」「按标题层级识别」或「不分章」。纯文本支持自动识别、UTF-8、UTF-16 与 GB18030 编码；Word 不需要选择文字编码。
3. 点击「预览」，检查识别出的卷章、字数与正文。长篇可在预览中调整卷名、章名；更换文件、作品类型、分章策略、编码或作品名称后需重新预览。
4. 确认后点击「导入为新作品」。每次确认创建独立作品，不覆盖书架上已有的书；同一次确认因连接中断而重试，不会重复建书。

短篇始终导入为一篇连续正文，不建立分卷或篇章。导入只建立稿件的卷章和正文，不自动生成故事大纲、人物或 AI 记忆。导入成功不计入当天新增写作字数。

Word 仅保留正文、表格文字及可识别的标题结构，图片、Word 批注和排版不导入；旧版 `.doc` 不支持，请先另存为 `.docx`。Markdown 按标题和文本导入，预览中可检查代码围栏等内容；不下载外链图片。需要迁移封面、大纲、人物、应用内批注、书签和回收内容时，使用逐书完整 JSON。

## 写作与布局

左侧统一使用「写作」，页面按作品类型切换布局。

- **长篇：**按卷与章节组织。卷可折叠、改名、填写说明及调整顺序；章节可新建、移动、改名或暂不归卷。回收卷前需先移走其中的活动章节。章节目录与正文标题双向同步，改名保留关联，目录底部显示全书总字数。
- **短篇：**一篇连续正文，不设卷章目录，也不能新建篇章。大纲、人物、创作工具、查找替换、历史与 AI 仍可使用。旧版活动短篇内容按原顺序用空行衔接，回收内容保留，原数据在首次保存前的历史中可查。

正文为纯文本，支持中文输入法及原生撤销、重做。停止输入约 0.65 秒后自动保存；`Ctrl+S / Command+S` 立即保存。输入、中文选字与自动保存保留当前正文位置，正文高度变化不会将长章拉回顶部。专注模式可用 Esc 退出，正文字号可调为 16–26 px。

字数按 Unicode 非空白字符计算，包含标点和英文字母，排除空格及换行；它不是英文单词数量。

工具栏「作品大纲」在写作侧栏中编辑世界观、角色、剧情和故事梗概，使用当前作品已有的大纲节点。空白填写提示由滚轮或键盘手动浏览，不自动滚动；输入后只显示所写内容。人物卡片可跳转已有档案。

大纲与写作页的目录、正文、AI / 资料栏边界可拖动，按页面记住宽度；双击恢复默认，也支持键盘方向键。太阳 / 月亮图标切换日夜；「设置 → 通用」切换语言与护眼模式，只改变界面，不翻译作品内容。

Mac 使用原生红黄绿窗口按钮，支持双指滚动、人物图双指平移与捏合缩放。非编辑区横向返回和 `Command + [` 先保存，再返回书架；实体触控板手感仍需实机检查。

### 对照修改

从写作工具栏的「对照修改」图标打开，长篇和短篇均可使用。两栏对应同一章，左侧保留只读原文，删改文字标红，新增位置显示绿色标记，悬停可查看新增内容；右侧编辑独立修改稿。两栏默认等宽，标题与正文对齐，中间边界可拖动，窄窗口上下排列。

输入后的自动保存和 `Ctrl+S / Command+S` 保存本机独立对照稿，不改正式正文。两份稿件及差异在退出、重开和重启后继续保留；只读原文不会因保存修改稿而变成新基准。

| 退出方式 | 结果 |
| --- | --- |
| 再次点击工具栏「对照修改」图标 | 保存独立对照稿后退出，不采用到正文；恢复当前正式正文 |
| 右上角叉号 → 保存修改 | 明确采用修改稿到正式正文，然后退出；仍保留原文与修改稿供再次查看 |
| 右上角叉号 → 不保存退出 | 保留两份对照稿后退出，不采用到正文 |
| 右上角叉号 → 取消 | 留在对照界面继续编辑 |

右上角叉号在对照模式下替代章节上移、下移和删除，退出后恢复原操作。切换章节、作品或离开写作前先保存独立对照稿；保存失败时保留当前界面供重试。原生撤销、输入法、选区和滚动沿用正常编辑流程。

明确采用时，在同一事务中更新正式正文、历史和写作活动，对批注与书签重新定位；后续导出、备份及同步使用已采用的正式正文。采用前检查正文与草稿版本，正式正文若已在其他位置修改，需再次确认替换当前正文；确认期间再次变化时停止操作，保留两稿供重新检查。

独立对照稿仅在本机数据库中，不进入逐书 JSON、正文导出、作品历史、自动备份或同步；未采用的修改不计正文产量。相关章节或作品被彻底删除时清理对应对照稿。

长篇还可从「⋯」菜单进入「卷章整理」，拖动排序、勾选章节批量移卷或合并；「拆分当前章」按光标或选区分开正文。短篇保持一篇连续正文。

### 素材与跨书搜索

「写作工具 → 素材库」保存本书的图片、PDF、文字和手动网页摘录，可关联章节和资料。单文件最多 5 MiB，二进制合计最多 15 MiB、最多 120 项，同时受整书容量限制。附件随完整 JSON 和自建同步迁移；网页内容需手动填写，PDF 不自动做文字识别。

顶栏搜索图标查找所有活动作品的正文、大纲、人物、关系及素材摘录，点击结果定位原记录。它与下方当前书的查找替换分开使用。

## 全书查找与替换

在写作工具栏点击放大镜，或按 `Ctrl / Command + Shift + F / H` 打开。

1. 输入查找文字与替换文字，选择是否区分大小写。按普通文字匹配，正则符号不作为表达式执行。
2. 匹配按章分组，显示数量和原文片段。点击片段定位对应正文；每章最多显示前六处片段，数量包含本章全部匹配。
3. 勾选要操作的章节，点击「替换选中章节」。操作包含所选章节的全部匹配，短篇只操作这一篇正文。
4. 执行前再次检查保存状态和来源正文；若另有编辑、切书或版本冲突，需重新预览。完成后保存，原稿进入历史版本。

只查找未回收正文，不改书名、章名、大纲或人物资料。替换文字原样写入，`$1`、`$&` 等保留字面内容。替换为空可删除匹配文字。超出章节或作品容量的结果不会应用。

## 本地校对

在写作工具栏点击「校对与批注」图标，再选「本地校对」。默认检查当前章，也可切换「全书」；短篇检查连续正文，回收内容不参与扫描。

- **常见错词：**内置 20 组固定规则，如「迫不急待 → 迫不及待」「再接再励 → 再接再厉」。检查原文片段后逐条勾选，或选择全部可修正项，点击「修正选中」。没有默认勾选，也不会自动应用建议。
- **重复与标点：**提示部分重复功能词、重复标点、未配对引号 / 括号和中文段落中的英文标点。这些项只提示和定位，不参与批量修正；拟声重复、省略号及英文缩写等不会被强行改写。
- **忽略与保护：**可忽略本次结果，或将词加入当前书的自定义词典。每书最多 500 个词，每词 1–100 个 Unicode 字符。已有的人物姓名及别名自动受保护；只有完整提示落在保护词内才忽略，单字不会遮蔽整条错词。

点击提示中的原文定位准确位置。「规则与词典」可添加或移除保护词，修改随该书正常保存。校对完全离线，不调用 AI，也不把稿件发到网络。

修正前核对书籍、保存版本及来源正文；期间稿件变化需重新校对。成功修正进入普通保存与历史版本，保存失败时保留已修正的当前草稿供重试。规则集用于发现有限的常见问题，未发现提示不代表全文已经完成校对。

## 段落批注与书签

在正文中选择文字，再从写作工具栏「校对与批注」选择「添加批注」或「添加书签」。也可在正文编辑框内按 `Ctrl / Command + Shift + M` 添加批注、`Ctrl / Command + Shift + B` 添加书签。未选中文字时，关联光标所在的非空段落；每次最多关联 20,000 个 UTF-16 字符单位。

批注可填写标题、修改想法并标记「已解决」，书签可命名。打开「校对与批注 → 批注 / 书签」查看当前正文或全书记录，点击「跳转原文」返回对应位置。记录属于当前作品，修改随自动保存写入本机。

关联以正文位置、原文及上下文共同确认。插入前文后位置随编辑移动，修改被关联段落内部文字时会更新其引用；原文被完整删除、替换，或相邻重复段落产生无法确认的位置时，标记「原文已变更」，不跳到其他同名句子。可点击「重新关联」，选择目标正文与新选区，确认后恢复跳转。正文撤销或历史恢复后，仍以实际保存的原文和范围核对，失效关联不会凭相同文字自动复活。

回收章节保留其批注与书签，恢复后可继续查看；彻底删除章节会清理对应关联原文和上下文，并同步清理历史与 App 自动备份中的相关记录。完整 JSON 包含每书的 `reviewTools`：自定义词典、批注及书签；TXT、Markdown 和排版导出不携带这些编辑资料。

## 大纲、人物与正文关联

大纲按全书、分卷、章节和情节 / 设定分层，可添加子节点、调整顺序、设置所属卷与主题。主题可自定义，搜索查标题和内容并保留上级路径。主题、层级及卷筛选收在「大纲分类」中。

长篇的「生成卷章目录」可从分卷和章节大纲创建卷及空白章节，不把策划文字填进正文，也不覆盖已有正文或重复建立已关联目录。「完整阅读」连续展示大纲，左侧目录和关联正文使用文字跳转，点击标题可编辑对应节点。

人物档案可填写姓名、别名、分组、定位、目标、弱点、去向与分卷变化；关系可记录类型、阶段、说明和关联卷章。人物脉络提供三个视图：

| 视图 | 查看与编辑 |
| --- | --- |
| 主脉络 | 默认展示主角及直接关系。右侧人物图标可选择成员，也可恢复自动选择；手工空选择会保留，不自动补入人物。卡片显示身份与目标，点人物阅读档案，点连线阅读关系 |
| 总脉络 | 展示全体人物，保留分组、卷、关系类型筛选与关系索引。自定义主题分图允许同一人物出现在多张图中，编辑主脉络不会改写这些分图 |
| 人物成长轨迹 | 长篇按人物行与卷列排列，显示卷章范围；点击卡片完整编辑既有分卷成长内容，点击人名打开档案，点击正文链接跳转。长内容显示摘要，窄窗口可在矩阵内部滚动 |

成长轨迹直接使用人物档案中的分卷变化，两处共用同一份数据；分组或卷筛选不删除未显示内容。短篇使用愿望与目标、矛盾与弱点、最终去向三列，不新增虚构卷章。主脉络成员与成长内容属于作品，随完整 JSON、历史和自动备份保存。正文提及与关联链接用于核对，成长规划不代表事件已经在正文中发生。

大纲、人物及关系中的「关联章节」连接本书正文；正文的「关联大纲 / 人物」和「关联与资料」提供返回入口。固定编号使改名与排序不影响关联。通常定位到章节，查找结果可以进一步定位匹配文字。回收章节不可直接打开，恢复后既有大纲及人物关联可继续使用。

姓名和别名匹配使用本地规则，生成正文自动提及；同章提及可能来自回忆、对白或转述，不保证人物在场，更不自动确认亲属、友谊或冲突。手动关系画实线，自动同章线索画虚线，默认关闭自动线索。人名识别同样是待确认的本地候选，作者核实后才建立人物。

## 创作工具

在大纲或写作工具栏点击「创作工具」，查看当前书的伏笔追踪与故事时间线，修改随正常保存写入作品。每日目标与统计从左侧「首页」进入。

### 伏笔追踪

新建伏笔，填写标题与说明，设置「埋下」「推进」或「回收」，选择关联正文及人物。关联文字可直接跳转。默认筛选「未回收」，也可查看全部或指定状态，用于检查仍需推进的线索。

状态由作者维护，程序不凭关键词自动判断伏笔已经回收。示例中备用灯未修线路、旧馆四只待查箱子及待确认的新地址保留未回收状态，已核实的旧案线索标为回收。

### 故事时间线

事件包含标题、故事时间、说明和人物 / 正文链接。时间可写公历，也可写「第三日清晨」「返潮后第十四日」等自定义文字；程序不猜测历法。用「上移 / 下移」明确事件顺序，保存和导出沿用此顺序。

### 每日目标与统计

左侧「首页」汇总书架活动作品的今日新增、总字数、连续写作、7 / 30 天趋势和写作日历。累计与连续写作天数覆盖全历史，日历提供近 90 天。每日目标在首页调整，独立于各书保存。日期使用运行 App 的电脑本地日期；目标设为 0 可取消目标进度。

产量在正文成功保存的同一事务中记录，按各章正文的正增量累计。删除或缩短不产生新增量；导入、示例载入、旧短篇合并、回收章节恢复、整版恢复和逐段恢复不计产量。元数据修改不计量，保存冲突或事务失败不会增加数字。活动统计不代表键盘敲击次数或完整编辑时长。

伏笔、时间线和旧版逐书目标随完整 JSON、历史及自动备份保留。首页每日目标保存在独立本机设置中，不随单书 JSON 迁移。写作活动记录只在本机数据库中，逐书 JSON 不携带活动记录；导入为新书后今日产量从 0 开始。彻底删除整书会清理该书统计；回收章节会移除创作工具中对应链接，恢复章节不会自动重建这些链接。

## 保存、备份与删除

桌面数据库在系统用户数据目录 `writer-desk/data/writer.sqlite3`，从「设置 → 关于 → 本机数据目录」查看实际位置。源码浏览器版默认使用项目内 `data/writer.sqlite3`。默认只保存本机；可在「设置 → 同步与协作」启用自建服务，配置见[自建同步与手机写作](self-host-sync.md)。

每本书的「导出与备份」只操作该书：

| 格式或操作 | 内容与用途 |
| --- | --- |
| TXT / Markdown | 按阅读顺序导出未回收正文，用于通用文本交换 |
| 完整 JSON | 封面、卷章、大纲、人物关系、分图、伏笔、时间线、旧版逐书目标、已保存长篇记忆、自定义词典、批注、书签、内嵌素材及回收内容，用于继续编辑和迁移 |
| 排版导出 | Word、EPUB、PDF，用于阅读和分享 |
| 历史与自动备份 | 预览、对比或恢复当前书的旧稿 |

JSON 导出为 v4，兼容导入早期 v1–v3；导入创建独立作品，不覆盖原书，旧长篇会补默认卷并保留正文及关联。旧版 App 会拒绝 v4，避免丢失附件。JSON 不含本机独立对照稿、AI 对话、聊天图片、密钥、用量账本、Skill 和写作活动统计；对照稿也不进入逐书自动备份或同步。确认采用后的正式正文按正常规则导出与备份。

「设置 → 保存」调整自动备份，默认成功保存后每 5 分钟生成快照，每书保留 20 份；未编辑时不重复生成。可手动立即备份，独立快照在数据目录 `backups/` 中。重要作品的完整 JSON 请另存其他磁盘。手动复制数据库前先正常退出 App，或复制整个数据目录；运行中不要只复制 SQLite 主文件，近期写入可能在 WAL 中。

「设置 → 保存 → 外部备份」可另选硬盘或文件夹，App 只管理其中有所有权标记的专有子目录，本机快照继续保留。外部盘离线不阻止写作，需要清理时保留待处理记录，重新连接后重试。

未完成输入会尽力保留本机草稿，但草稿不代替数据库与独立备份。失败时保留本页内容供重试或下载；两个窗口编辑同书会检查保存版本，冲突时可另存新书，避免覆盖另一个窗口。

整书「移入回收站」后保留 30 天，可恢复或手动彻底删除；App 关闭期间到期的，下次启动清理。整书彻底删除清理正文、资料、历史、App 自动快照、本机对照稿、聊天图片与统计。自行导出和系统备份不在清理范围。

章节可单独回收，左下角「历史记录」显示所属书、删除时间和只读预览，可恢复或彻底删除。未知旧删除日期显示时间未知。彻底删除章节会清理当前稿、保存历史、自动备份、App 生成且未被手改的书籍文件夹副本及章节关联，包含批注 / 书签的原文和定位上下文，同时清除相关独立对照稿，以及该书本机草稿、AI 对话和聊天图片；旧历史恢复或旧窗口保存不能重新带回已清理编号。其他正文与策划保留。

若书籍文件夹中的导出被手动修改，会提示先处理该文件。磁盘清理失败保留待清理任务并重试，不报告全部完成。App 不能清理独立导出、系统备份或物理磁盘恢复痕迹，也不能远程擦除离线或已撤销设备的本机副本。

## 联网更新

在「设置 → 安装与升级 → 联网更新」检查和下载对应系统、架构的安装包。需要后续测试版时启用「接收预览版」。下载完成校验 SHA256，保存并退出后安装；自动下载默认关闭。

GitHub 匿名接口限流或服务故障时，会自动读取固定官网更新索引。Linux 托管安装使用固定入口升级，DEB 交给系统安装器；Windows 等旧进程正常退出后启动安装器，Mac 打开已校验 DMG 的安装引导。

## 版本差异与恢复

先打开目标书，再从左下角「历史记录 → 历史版本与差异对比」进入，也可用该书「导出与备份 → 历史与自动备份」。

选择历史版本或本机备份并预览正文，点击「对比当前稿」。长篇可选择两版共同存在的活动章节，短篇比较连续正文。红色删除线表示旧稿，绿色表示当前稿；勾选需要的变化，点击「恢复选中段落」。未勾选的部分保留当前稿，其他章节不改。

应用前会再次保存并核对来源；期间正文变化、切书、删除源章节或出现版本冲突时停止操作。恢复前的稿件保留在历史中，成功后正常保存，恢复的文字不计入新增产量。需要完全回到旧稿时用「恢复此版本」，同样先保留当前版本。

差异按段落展示，较大改写可能以整段增删表示；不是逐字合并编辑器。已彻底删除的章节不会因旧版本对比或恢复而重现。

## 排版导出

在书架该书「导出与备份 → 排版导出」中选格式、模板、纸张、字体及是否包含封面 / 目录，然后导出。模板可另存并复用，设置页边距、行距、缩进与章节标题样式。读取最近成功保存的本书数据，按卷章阅读顺序排版并排除回收正文。

- **Word `.docx`：**包含标题、卷章样式、可点击目录及正文段落；可在 Word / WPS 中继续排版。实际字体与分页受阅读软件和已安装字体影响。
- **EPUB `.epub`：**包含可重排正文、封面和导航目录，纸张选择不适用。
- **PDF：**桌面版使用本机打印排版并选择保存位置；源码浏览器版打开系统打印窗口，选择另存为 PDF。

短篇保持一篇连续正文，不添加卷章目录。封面以本机已有素材生成，WebP 在导出时本地转换为通用图片格式，不改变原书封面。导出不调用 AI，也不上传正文。排版文件不包含完整策划或回收站，不能替代 JSON 备份。

## AI 辅助

「设置 → AI 服务」填写兼容 Chat Completions 的 API 基础地址、密钥和模型，再启用。地址通常为服务提供方的 `/v1` 等基础地址，支持 HTTPS 及本机 HTTP。可读取 `/models` 列表，不提供列表时手动输入模型。模型列表读取不发送作品，密钥只放本机独立配置，不进入作品、备份或发行包。

可保存多套独立 AI 服务，在对话框旁切换服务和模型。「AI 用量记录」显示提供商实际返回的 Token、耗时及按自填单价计算的费用；未返回用量或未填写单价时显示不可用，不为统计重复调用服务。

大纲与写作右侧对话栏支持自由提示词、可修改预设任务和图片输入。Enter 发送、Shift+Enter 换行，中文选字时不发送；底部模型可切换。每本书分别保留大纲和写作对话及未发送提示词，「新对话」开始新的交流，对话不进入 JSON 备份。

回复随流式数据逐步显示。点击「停止等待」结束当前请求，未完成结果不能作为可采用候选，也不会写进正文；下一轮可继续发送。服务明确不支持流式参数时回退一次普通请求；流中断不自动重发请求。停止后的服务端费用按服务提供方规则结算。

生成大纲、草稿、人物关系、一致性检查或长篇记忆时，在消息中先预览和编辑，再勾选采用。大纲可继续生成卷章目录；草稿可追加或建立新章；短篇追加或替换连续正文。来源已变化的候选需重新整理。正常聊天不会自动改写正文与策划。

资料与 Skill 在折叠区选择。上下文默认由模型服务校验，不设固定 250,000 字符上限，不悄悄截断已选资料；高级选项可启用手动字符保护。选择的正文、相关记忆、Skill 和对话前文计入发送内容。只有显式发送或生成操作才调用配置的服务。

「封面与书名」中的 AI 先生成候选书名和封面提示词；图像模型需服务支持 Images API。书名排版在本机完成，图片先预览再采用，不因普通对话自动调用图像模型。

提示词框按输入自动伸缩。底部「＋」或粘贴支持 PNG、JPEG、WebP，发送前可预览、移除，消息图片可放大查看。每消息最多 4 图，每图 8 MiB，单次请求含历史图片合计 20 MiB。图片原件独立存于本机 `ai-chat-images/`，不进入作品 JSON。识图需要视觉模型，只显示验证后的内联图片，不自动抓取外链。

### 长篇记忆

从对话栏「资料 → 长篇记忆」查看章节摘要、人物状态及设定规则。本地默认从章节开头 / 结尾、人物最近提及和规则片段摘录，不调用 AI；摘录不保证完整概括，提及也不保证是人物当前客观状态，需要结合原文核对。

可编辑记忆、恢复本地摘录并保存。续写时按相关性选取最多六个此前章节的记忆；已勾选正文仍完整发送。关闭「自动选取长篇记忆」可不附加这些记忆。此功能也支持短篇，短篇不会被拆成虚构章节。

需要模型概括时，选「整理长篇记忆」任务并勾选来源正文。AI 只返回候选，作者确认采用后成为已保存记忆，不改写正文。每项带章节来源与指纹；章名或正文变化后旧记忆标记过期，发送时改用最新本地摘录，旧摘要可查但不继续当作当前记忆。回收章节不参与记忆选取；彻底删除章节清理对应已保存记忆，旧快照不能将其带回。

### 本机写作 Skill

「设置 → 写作 Skill」支持本机的 `chinese-novelist`、`novelskill`、`human-writing`。来源为 `$CODEX_HOME/skills`，未设置时用 `~/.codex/skills`；导入副本在本机 `writing-skills/`，源文件不变，更新后可重新导入。

可查看规则与参考，保存默认选择，或在对话中临时更改。选定规则在显式发送时作为上下文交给已配置服务；程序不执行 Skill 脚本、不自动建立外部小说目录。Skill 不随作品、GitHub 源码或安装包分发，另一台电脑需单独导入。

## 容量与验收边界

单章正文最多 500 万字符，单书总大小上限 25 MiB，完整备份导入上限 50 MiB；稿件文件导入上限 12 MiB。每类批注或书签最多 5,000 条，单次关联原文最多 20,000 个 UTF-16 字符单位，自定义词典每书最多 500 项。AI 图片限制见上文。

AI 协议验收使用本机模拟服务，未消耗真实付费模型额度；不同兼容服务的长上下文、识图及图像生成仍需使用实际配置验证。Word 已检查结构与完整文字，当前环境未完成 Word 实际渲染；PDF 已实际导出十万字示例，验证自定义纸张及 Letter 尺寸；逐页人工排版审校和 Word 阅读器实际分页仍未完成。此前验证见[0.6.0 验收记录](acceptance-v0.6.0.md)，0.6.1 修复记录见[打包验收](acceptance-v0.6.1.md)。稿件导入、校对与批注见[0.7.0 验收](acceptance-v0.7.0.md)，素材与同步见[0.8.0 验收](acceptance-0.8.0.md)，首页、对照布局与图标整理见[0.8.2 验收](acceptance-0.8.2.md)；本轮人物视图与独立对照稿见[0.8.3 验收](acceptance-0.8.3.md)。
