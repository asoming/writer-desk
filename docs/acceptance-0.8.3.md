# 作家工作台 0.8.3 验收

本轮增加主脉络、总脉络和人物成长轨迹，并将对照修改改为独立保存的双稿。所有测试使用隔离临时书库，未使用真实用户稿件。

## 人物与成长轨迹

- 主脉络默认使用主角及直接关系，也可手动选择成员；总脉络保留全体人物、分组、关系筛选与原有主题分图。
- 成长轨迹直接使用人物档案的分卷成长内容，不另建重复人物数据。长篇按人物与卷排列，可编辑并查看人物相关正文。
- 短篇保留连续正文，展示人物动机、矛盾与最终去向，不生成虚构分卷。
- 检查包含 32 人、6 卷、36 章、101,506 字示例。主成员的缺省、手工空选择、回收恢复与章节 / 人物编号相同的边界已覆盖。

## 对照修改

- 原文与修改稿保存在独立 SQLite 表；输入、自动保存、Ctrl / Command + S、普通退出和重启均不将修改稿写入正文。
- 工具栏图标可以切换并直接退出；右上角叉号显示保存修改、不保存退出与取消。退出后恢复正文，再次打开保留两稿与差异，确认保存后仍保留原文基准。
- 确认保存原子更新正文、历史、字数统计与对照检查点；批注和书签按修改后的正文重新定位。
- 草稿版本及正文检查点防止跨窗口覆盖。正文变动后仍可保存旧对照稿，采用时必须重新确认；相关永久删除清除对照稿并使在途请求作废。
- 同一对照稿的保存请求逐次执行，覆盖中文输入法、撤销、并发保存、切换章节 / 作品 / 首页、重启与删除后的晚到响应。

## 数据范围

成长轨迹和主脉络成员属于作品，随完整作品 JSON 和备份保存。未采用的对照稿仅保存在本机独立数据库表，不计正文产量，也不进入正文导出、单书 JSON、作品历史或同步数据。正式采用后的正文按原有导出和备份逻辑处理。
