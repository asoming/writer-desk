# 作家工作台 0.4.7 验收记录

## 本次功能

大纲和写作页均使用可收起的右侧 AI 对话栏，底部提示词框与右侧发送按钮；Enter 发送、Shift+Enter 换行，中文输入法选词不会误发送。生成大纲、写作草稿、人物与关系、一致性检查有可修改及恢复的预设提示词，也可以自由对话。界面支持中英文。

每本书的大纲和写作分别保存会话与未发送草稿，保存在本机客户端存储，当前不随作品 JSON 备份导出。连续追问以原生 user/assistant 消息完整发送既往对话和候选；资料预览在本机完成，只有明确发送才请求配置的 AI。自动上下文不再使用 250000 字符限制，手动模式计入历史与本轮要求。

候选在消息中预览，明确采用后才写入作品，保留版本冲突、失败重试与一次采用保护。修复收起侧栏、打开设置或普通对话框期间返回的候选，以及重新打开会话后，候选采用控件缺失的问题。已有候选的编辑值与失败保存状态不会因收起或设置刷新而丢失。
