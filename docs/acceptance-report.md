# 作家工作台 0.4.5 验收记录

## 本次功能

书名右侧加入离线骰子取名，中文和英文各 24 个候选，避免连续重复。十款不同画法的本机模板为山海、星轨、夜航、花信、霓虹、远山、诗笺、波纹、绿意、曙光。模板随书名更新，上传与文字封面保留，长短篇均支持。封面与模板选择随保存、逐书备份及恢复保留。

AI 新增「生成封面与书名」，默认提示词可编辑或恢复。先预览名字与图像提示词，再明确调用配置的图像模型；名字修改只在本机重新排版。新书保存前可预览，已有书参考本书大纲及人物；候选回填编辑框后仍需保存。书内 AI 采用保持版本冲突和保存失败重试保护。图片请求只发送到已配置服务的同源 Images API，严格验证内联 PNG/JPEG/WebP，不抓取远程图片 URL、不自动重试。
