# 作家工作台 0.3.3 验收记录

验证日期为 2026-10-09。本版为长篇和短篇书架上的每本书增加「打开文件夹」。默认十万字演示库见 [0.3.2 记录](acceptance-0.3.2.md)，连续大纲与导航见 [0.3.1 记录](acceptance-0.3.1.md)。

## 作品文件夹

每本书右侧的「打开文件夹」与「封面与书名」并排。桌面版先保存当前编辑，再用系统文件管理器打开指定作品的独立目录，不切换当前书和页面。文件夹首次点击时建立，包含按卷章排序的 `正文.txt` 和完整 v3 备份 `作品.yejian.json`。此后 App 成功保存会更新已经建立的文件夹；正文过滤回收内容，完整备份保留回收、分卷、大纲、人物、分图和全部关联。

![书架文件夹入口](book-folders-v0.3.3.png)

目录位于作品数据目录的 `books/book-<作品编号的SHA256>/`。同名作品分开，改名不改变目录，用户额外放入的资料保持原样。应用只更新自己生成且未被外部改动的文件，遇到同名文件或外部修改时不覆盖，并给出中英文提示。外部修改不会自动导入 App。网页版显示可复制的实际目录路径。

SQLite 仍为保存依据。目录导出失败时，已成功写入的作品保留，并显示文件夹同步警告；不把导出问题误报为正文保存失败。同步在跨进程 SQLite 锁中读取最新版本，单文件原子替换，双代清单支持中断恢复。文件夹不接受任意路径参数，目录和产物拒绝符号链接。
