# 作家工作台 0.4.2 验收记录

验收日期：2026-10-10。本次补齐整书回收、AI 大纲、自定义任务与可修改提示词。使用隔离数据库、本机模拟 AI 服务及临时安装目录验证，未调用外部模型。前版 Skill 验收见 `acceptance-0.4.1.md`，备份与历史见 `acceptance-0.4.0.md`。

## 本次完成

- 书架每本长篇、短篇右侧加入「移入回收站」。回收前保存，封面、正文、卷章、大纲、人物、关联、历史与文件夹保留，作品从书架计数中移除。
- 左下角「回收站」无需打开作品也可使用，可恢复整部作品。回收默认示例后重启不会补回，全部书籍回收后也不会重新初始化示例。
- 多窗口对同一书籍回收、恢复、保存时校验版本；旧窗口不能覆盖或复活回收作品。未保存的内容可另存新作品、下载备份，或核实本机草稿保存成功后返回书架。
- AI 辅助新增「生成大纲」，空白新书可以直接使用。生成总纲、分卷、章纲与设定，先编辑、勾选，再明确追加到本书。选择子节点会同时选择父节点，不覆盖已有策划，不写入正文；再使用「生成卷章目录」建立目录。
- 四项预设任务各有完整提示词，可编辑或恢复默认；同一对话框切换任务保留本次修改。发送内容以界面文字为准，提示词和 Skill 均计入上下文上限。
- 新增「其他 / 自定义」，初始提示词为空。结果按普通文字显示，可编辑、复制，不自动修改作品。
- 所有新增入口和预设提示词支持中文与 English，作品原文不随界面翻译。

## 十万字示例与实际界面

《潮汐档案馆》保持 101,506 个非空白字符、6 卷、36 章、32 位人物、49 条大纲、6 个主题分图、35 条手动关系。

实际书架界面将完整示例回收，长篇计数从 2 变为 1，回收站可以显示并恢复该书。恢复后仍为 6 卷、36 章、101,506 字。截图见 `trash-v0.4.2.png`。

实际新建无正文章节的长篇，打开大纲 AI，修改提示词，切换到自定义再切回，修改仍保留。本机模拟服务核对实际发送的操作与提示词；大纲请求 702 字符、0 章，自定义请求 1,300 字符、0 章。大纲结果预览中编辑标题，勾选章纲自动连选上级，勾选设定后采用，连续阅读显示编辑后的策划。

自定义服务返回自由文字，其中 HTML 标签作为普通文本显示。界面可以编辑并复制结果，作品不会因此改变。切换 English 后五种任务、默认提示词和按钮显示英文，书名与大纲原文保留。截图见 `ai-v0.4.2.png`。

最终空白新书验收中，采用 AI 首卷后「生成卷章目录」显示新增 0 卷、1 章，确认后写作目录仅有「第一卷 河岸旧事」及「第一章 迟到的信」，正文为空。严格空白模板可复用；13 种已修改作品场景保持追加，不动原内容。
