# 作家工作台 0.4.8 验收记录

## 功能

设置改为用户选定的分组面板布局：浅灰背景、白色圆角设置组，按通用、AI 服务、写作 Skill、保存、快捷操作、安装与升级、关于分类。分类切换只隐藏页面，不重建表单，因此未保存的 API Key、模型和 Skill 选择保留。原生窗口、保存、语言、编辑命令和升级动作保持原契约。

兼容 Chat Completions 的服务地址可读取 `/models`，支持基础地址与完整生成路径。设置页与对话输入框底部都可选择、刷新模型，也可手动填写。空配置不擅自选择列表第一项；模型保存完成后才可发送，请求携带明确的模型快照。读取列表不发送作品或保存未提交的配置。修复模型保存成功及失败期间跨页面的显示竞态，以及保存成功后旧本机存储警告残留。

大纲目录、章节目录、右侧 AI 与资料栏可拖动调整，大纲和写作分别记住宽度。支持方向键、双击或 Enter 恢复默认；窄窗口临时缩窄或转为抽屉，不覆盖作者保存的宽度。

## 源码和界面

20 个 JavaScript/UI 测试文件通过 126 项 node:test 测试和 123 个自定义检查组。桌面及升级器 2 个脚本通过 17 组检查。后端 14 个脚本通过 107 项单元测试和 22 组集成检查。独立复查验证 12 项新增设置和分栏标签的英文翻译，并复现、修复、重新验证模型保存失败跨页面的竞态。

实际浏览器使用隔离书库和本机假 API，验证设置分类保留输入、语言切换、520 像素窄窗口无横向溢出、模型读取和明确选择、所选模型实际送达、分栏鼠标与键盘调整、重载记忆、写作与大纲宽度独立、缩窗恢复。浏览器无警告或错误。截图为 `settings-v0.4.8.png` 和 `layout-v0.4.8.png`，其中模型及回复来自本机模拟服务。
