# 作家工作台 0.4.13 验收记录

## 功能

写作工具栏在所属卷与 AI 辅助之间新增作品大纲，侧栏按世界观、角色、剧情大纲和故事梗概编辑当前作品已有的大纲节点。空白时显示完整填写参考，超出空间的提示文字往返上下移动，不显示滚动条；输入后提示隐藏，不把提示保存成正文。系统减少动态效果时取消动画，仍可滚动阅读。人物卡片使用已有资料，可跳转人物脉络；短篇保持一篇连续正文，其提示不含卷章结构。

回收站上方新增历史记录，按作品展示已删除章节、删除时间和只读正文预览，支持恢复及单章彻底删除。旧数据缺少可靠日期时显示时间未知。回收站章节行也显示时间并提供彻底删除。

彻删会精确移除当前稿、保存历史、自动快照及受管理导出中的目标章节，保留其它章的内容和历史。App 崩溃遗留的归属可确认临时文件也处理。旧短篇按 UTF-16 范围去除目标段，剩余正文及关联保留。作品文件夹中手动改过或归属无法确认的文件会阻止操作，外部文件不会被擅自删除。

本书草稿、AI 对话和聊天图片同时清理，清理回执只保留编号和时间。旧版本恢复、过期窗口 PUT 和在途 AI 响应不能重新带回清除内容。失败保留持久清理任务，后台或历史记录可重试；未全部完成时不报告完成。自行导出、系统备份及物理磁盘恢复不在 App 清理范围内。

## 验证

29 个 JavaScript／桌面脚本、18 个 Python 后端脚本全部通过，最终测试前后源码散列一致。包括 183 项 node:test、158 组既有检查和新增作品大纲模块检查；后端 151 项单元测试及 22 组集成检查。新增删除生命周期测试覆盖 SQL 回滚、WAL 占用、磁盘失败重试、其它书隔离、手改副本阻止、短篇旧格式、孤儿临时文件及 importlib 兼容。

真实浏览器使用独立测试库检查侧栏和完整大纲同步、提示隐藏、文字动画和隐藏滚动条、键盘调宽、AI 互斥、每书独立、短篇布局、删除时间、正文预览、恢复、删除范围弹窗、中英文和夜间颜色。最终发行包界面再次打开验证。浏览器只检查删除确认，实际永久删除通过隔离后端测试进行。未使用个人书库作删除测试，未调用付费 AI。
