# 0.8.1 对照修改、更新检查与流式回复验收

日期：2026-10-15。此文件先记录实现和源码验证，原生安装包、发行摘要及本机安装将在本轮验收完成后补齐。

## 功能

- 写作工具中的“双稿分屏”替换为“对照修改”。两栏对应当前同一章，长篇和短篇均可用。左栏保留打开时的正文快照，删改的原文字标色，新增位置显示绿色标记；右栏使用原来的正文编辑框，正常自动保存。
- 保存不会更新左栏基准。关闭后重新打开，使用当时正文作为新基准。切换章节、作品或离开写作会关闭并清空原文快照。彻底删除涉及内容时也清空快照。
- 对照只更新左侧 DOM，不为标色替换主编辑框或反复赋值；保留原生撤销、中文输入法、选区与滚动。长文本差异使用字符边界与固定计算预算，不建立整篇二次方矩阵。
- GitHub 匿名接口限流、服务故障或连接失败时，更新检查自动读取固定的 `https://asoming.github.io/writer-desk/updates.json`。索引由仓库工作流读取已公开发行生成，发布后及定时刷新；客户端不要求 GitHub Token。
- 备用索引仍使用相同的发行选择、平台 / 架构匹配、精确文件名、校验文件和安装包 SHA256 检查。非法地址、非法元数据、超限或取消不触发备用请求；索引成功返回且没有更新时正常显示已是最新版本。
- 大纲和写作侧栏继续提供 AI 流式回复。逐片段显示内容，完整结果校验后才保存为完成候选；停止保留部分回复和取消状态。
